# 设计决策蓝图

> 上游：requirements.md revision 2（scope = 本期）、PRD详细版.md、requirements-analysis.md（P0/P1 = 0）。标「用户确认」的项来自 2026-10-27 Design 提问；标「继承」的项来自 PRD 已确认决定。

## 1 盘子
- scope: 本期
- 端形态 / 响应式：桌面网页 + 钉钉内置浏览器，宽度 ≥ 1280 像素，不做手机布局（继承 NFR-006）
- 工作台聚合：按角色的「我的待办 + 关键数」（用户确认）
  - 所有角色：待填报、待审批、未处理预警（按其数据范围）
  - CEO、财务负责人额外：累计净利润达成率（原始 / 调整后）、最近季度预测偏差、当前编制任务提交率
  - 财务BP 额外：本月导入状态（金蝶、BI 最近期间）、BI 与金蝶差异超 3% 的组合数

## 2 信息架构 & 站点地图
- 导航模式：左侧分组侧栏 + 顶部面包屑；无权限的菜单直接隐藏（不置灰）
- 站点地图：
  - 工作台
  - 预算编制：编制任务（列表 → 任务详情/进度）｜我的填报（列表 → 平台渠道填报 / B端填报 / 成本比例填报 / 物流比例填报）｜部门费用（填报 → 专项预留额度）｜待我审批（列表 → 审批详情）
  - 预算版本：版本列表（发起季度调整 / 发起滚动预测 / 发布快照）→ 版本对比
  - 实际数：导入（金蝶月度 / BI 双月 / 历史）→ BI 与金蝶核对
  - 报表：公司汇总｜渠道×站点偏差｜品类×新老品偏差｜部门费用
  - 预警中心
  - 规则库：列表 → 规则详情（编辑 / 审批 / 版本历史）
  - 基础数据：渠道与店铺（含新渠道标记）｜SKU 对照表｜B端客户与部门｜科目映射｜汇率
  - 系统设置：角色与权限

## 3 角色 & 权限
- 上游已确认认证方式：钉钉扫码 / 钉钉工作台免登（继承 OQ-11）；无账号密码、无找回密码页
- 恢复路径：未开通权限、账号停用 → 登录页提示（AC-F01-02、AC-F01-03）
- 角色分层与能力边界：继承 PRD §2.1（8 类业务角色 + 信息数字化部间接角色）
- 同页角色差异：数据按范围过滤；不可操作的按钮隐藏；物流物控在填报表格中只出现四个比例列

## 5 通用交互范式
- 填报：类 Excel 表格（用户确认）——维度列冻结在左，12 个月横向展开，单元格内编辑，支持整块复制粘贴，单元格失焦即保存并刷新合计；保存冲突按 AC-F04-10 提示刷新；超范围值单元格标红并提示范围
- 列表：分页（每页 50 条）+ 顶部筛选；表格页右上角「导出 Excel」
- 表单：提交时校验，必填项标星；提交、退回、覆盖导入、审批前弹窗确认
- 反馈：成功用轻提示（3 秒消失）；校验错误就地显示在单元格或字段旁；导入错误显示行号列表；业务通知走钉钉工作通知（继承）

## 6 视觉风格锚点
- 明暗：浅色（用户确认）
- 风格：克制的财务工作台，信息密度高，表格优先
- Category：B 端数据管理 / 财务工具
- 情绪：冷静、可信、不抢数字的风头
- 交互哲学：色彩响应（悬停与选中用底色变化，不用阴影浮起）
- 字体：系统中文字体（苹方 / 微软雅黑），数字用等宽数字对齐；不加载境外字体服务（内网可用）
- 偏差语义色：不利（超支、未达成）= 红，有利 = 绿，预警 = 琥珀（用户确认）
- 设计签名：表格行内的「达成条」——细横条表示实际占预算的比例，竖刻度线表示时间进度，一眼看出跑在进度前还是后

## 7 数据与集成
- 核心实体：用户与角色范围、渠道/店铺/站点、SKU/SPU/品类、B端客户、部门、预算科目与金蝶科目映射、汇率、编制任务、填报单位、预算版本（原始/调整/快照）、预算单元值、部门费用、专项与使用登记、金蝶实际、BI 实际、导入记录、偏差说明、规则与规则版本、预警记录、审计日志
- 外部对接：钉钉（登录 + 工作通知，服务端调用开放平台接口）；金蝶与 BI 只通过 Excel 导入（继承 OQ-10）
- 同步策略：导入后同步计算并评估预警；钉钉通知失败异步重试（AC-F11-05）
- 方案前置能力：钉钉企业内部应用 committed，信息数字化部 2026-11-30 前完成，无替代方案，阻塞 REQ-F01-01、REQ-F03-01、REQ-F11-02；运行主机见 §8

## 8 技术栈 & 架构 & 部署
- 运行环境（用户确认）：开发与验收在 Windows 本机运行；2026-12-01 编制开始前由信息数字化部部署到公司内部服务器（继承 NFR-006）。技术方案同时给出两种部署方式
- 架构：单体网页应用（前后端分离打包为一个服务）+ PostgreSQL；导入的 Excel 解析入库，原文件存服务器本地持久目录用于追溯
- 技术方向：后端 Python + FastAPI；前端 Vue 3 + 中文组件库 + 开源类 Excel 表格组件；具体版本在技术方案中按官方发布来源核实
- DEC-002 开发身份模拟：钉钉应用 11-30 才就绪，本机验收阶段提供「开发模式身份切换」以模拟各角色登录；该开关只在开发配置下可用，生产配置下强制关闭且登录页不出现入口
- 国内可达：不依赖境外 CDN、字体或托管服务；前端依赖随安装包打包

## 9 安全 & 运维
- 认证：钉钉身份；会话 8 小时无操作失效
- 脱敏：钉钉通知不含金额（继承 NFR-005）
- 备份：数据库每日自动备份，保留 30 天
- 审计日志：角色分配、目标版本、目标调整、导入、规则库的修改留痕 ≥ 3 年（继承 NFR-004）；本期不做审计日志查看页，财务负责人需要时由技术人员导出
- 操作可逆：导入覆盖保留旧记录（AC-F09-03）；版本只增不改；规则只出新版本
