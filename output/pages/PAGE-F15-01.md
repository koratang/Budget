## 2. 页面概述

### 2.1 一句话定位
把原「业财一体化工作台」首页搬进预算平台：一屏看收入、毛利、利润、现金流达成，以及哪些指标低于 80%。

### 2.2 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 口径一致 | 年度口径 F1 9,840、F3 31.4%、F4 553.9、F7 820，与原工作台一致（FLOW-38） |
| 识别 | 二级指标达成率 < 80% 的全部列出（示例数据 13 项） |
| 勾稽 | 10 项一致性校验全部可见，示例数据全部通过 |

### 2.3 不做什么
- **不做**本页编辑——指标在 PAGE-F15-02 / 03 维护，本页只读，CEO 与编辑者看到的内容相同。
- **不做**与平台预算年度联动——沿用原工具期间口径 2026 年 1–9 月（DEC-030）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | CEO 周明远（只读）、财务负责人 林晓、财务BP 陈思雨 |
| 频次 | 月度经营会前、指标导入后 |

**场景 A**：林晓打开驾驶舱，看到净利润 553.9 万元卡片顶边为红色（达成率 < 80%），右下「达成率预警」第一行是 F2.4 Lowe's 毛利额 73%，点「查看经营建议 →」进入 PAGE-F15-07。
**场景 B**：周明远切到「月度」→「03月」，页头期间变为「2026年 03月」，KPI 与图表全部按 3 月口径重算。

## 4. 信息架构

1. 页头（外壳）：标题 +「示例数据」标记、描述「财务与业务指标全景视图 · 业财联动穿透」、年度 / 月度切换、月份下拉（月度时）、期间标签
2. 示例数据说明条
3. KPI 卡 ×4
4. 收入与盈利能力趋势（组合图）
5. 两栏：渠道收入结构（环形图）｜渠道毛利率（折线）
6. 业财联动核心传导链（6 条）
7. 两栏：数据一致性校验 ｜ 达成率预警表

## 5. 界面内容

### 5.1 KPI 卡

| 卡片 | 指标 | 示例值 | 说明 |
| :--- | :--- | :--- | :--- |
| 营业收入 | F1 | 9,840 人民币 | 底部「环比 / 同比」，有利变动红（涨红跌绿），不利绿；年度维度无环比显示「环比 —」 |
| 毛利率 | F3 | 31.4 % | 同比 +4.0% |
| 净利润 | F4 | 553.9 人民币 | 同比 +25.0% |
| 经营性现金流净额 | F7 | 820 人民币 | 同比 +12.0% |

卡片顶边色按达成率：≥100 绿、90–100 墨蓝、80–90 琥珀、< 80 红；未填报显示「—」与「待填报」。

### 5.2 图表

| 图表 | 内容 |
| :--- | :--- |
| 收入与盈利能力趋势 | 柱 = 各月营业收入（万元，01–09 月：1,002 / 766 / 1,124 / 1,023 / 1,073 / 1,229 / 1,126 / 1,309 / 1,188）；线 = 毛利率、净利率（%）；下方一句结论（区间、累计净变化、净利率收于） |
| 渠道收入结构 | 环形图中心「总收入 9,840」；右侧 Amazon 36.2% / Wayfair 20.1% / HomeDepot 14.4% / Lowe's 12.0% / 独立站 17.3%；说明 CR1 与 F1.1 / F1 勾稽 |
| 渠道毛利率 | F3.1–F3.5 各月折线，末端标值；说明最高 / 最低渠道 |

### 5.3 业财联动核心传导链
6 行「业务动作 → 中间量 → 财务结果」：前 3 条财务口径（销售费用率、毛利率、存货周转天数），后 3 条业务口径（品效、降本率、有货率，业务指标未填报时显示「待填报」）。

### 5.4 表格与清单

| 区块 | 列 / 内容 |
| :--- | :--- |
| 数据一致性校验 | 10 项（渠道 Σ = 一级、市场 Σ = 一级、毛利额交叉、F4.9 = 七项费用率之和等），每项 ✓ / ! + 一级值、明细合计、偏差 |
| 达成率预警（低于 80%） | 编码、指标名称（财务 / 业务徽标）、责任部门、实际、目标、达成率；按达成率升序；容器内纵向滚动；无数据时「暂无低于 80% 的二级指标」 |

```
打开 → 外壳读取 API-F15-01 → 装入引擎 → 渲染

  ├─「查看完整联动图谱 →」→ PAGE-F15-04
  └─「查看经营建议 →」→ PAGE-F15-07
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |

| 边界 | 处理 |
| :--- | :--- |
