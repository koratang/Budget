## 2. 页面概述

### 2.1 一句话定位

让运营按「SPU 数量 × 品效」填写自己负责店铺 2027 年 12 个月的销售驱动，边填边看到人民币收入和毛利。

### 2.2 存在理由

1. 收入预算要从品效出发，按品类、新老品拆开，才能看出渠道和品类差异（US-F04-01）。
2. 运营习惯 Excel；表格必须像 Excel 一样能整块粘贴，否则填报效率低于现状。
3. 新渠道容易过度乐观，需要在填报当下就提示放量规则并留下理由（US-F13-01）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 计算刷新 | 保存一个驱动值后受影响合计刷新 P95 ≤ 3 秒（NFR-001） |
| 数据质量 | 超范围值 100% 不入库（AC-F04-02）；上传文件有错时 0 行写入（AC-F04-08） |
| 金额精度 | 合计与明细显示值之和差额 ≤ 0.01 元 × 明细行数（AC-F06-09） |

### 2.4 不做什么

- 不填采购成本占比、物流四项比例、库存索赔率、其他运营费用率——它们由财务BP（PAGE-F04-04）与物流物控（PAGE-F04-05）填报，本页只读引用。
- 不做审核、退回操作——在 PAGE-F07-02 审批详情完成。
- 不维护新渠道标记和放量上限——分别在 PAGE-F02-01 渠道与店铺、PAGE-F12-01 规则库。
- 不做季度调整、滚动预测的入口——属于 F08 版本页面。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 运营（运营部渠道负责人，如 Amazon 负责人王浩） |
| 人数 | 每个店铺 1 名填报人，同一店铺可能有多人被分配 |
| 技术熟练度 | 熟练使用 Excel |
| 使用设备 | 公司电脑，钉钉内置浏览器或桌面浏览器 |
| 使用姿势 | 编制期集中填写，常从自有 Excel 复制整块数据 |

### 3.2 核心使用场景

**场景 A：在页面直接填写（主场景）**
- 时机：编制任务发布后（2026-12-01 起），截止日前。
- 前置：已被分配该店铺（AC-F01-07），财务BP 已录入 2027 预算汇率。
- 动作：选择店铺 → 在单元格内输入或从 Excel 粘贴 → 失焦自动保存，收入、毛利、合计即时刷新 → 提交审核。

**场景 B：下载模板离线填写**
- 动作：下载模板 → 在 Excel 中填写 → 上传 → 全部通过则写入；任一行错误则整份不写入并列出全部错误。

**场景 C：新渠道填报**
- 时机：TikTok-US-01 被标记为新渠道（起始月 2027-03）。
- 动作：填报后某月人民币收入超过放量上限 → 该月单元格标注「超出新渠道放量规则」→ 在「超出理由」行填写 → 才能提交。

**场景 D：被退回后修改**
- 动作：在页面顶部看到退回人、时间、原因 → 修改 → 重新提交。

### 3.3 用户核心诉求

1. **像 Excel**：能粘贴、能连续录入，不用逐格点保存。
2. **即时可见结果**：改一个数立刻看到收入和毛利变化。
3. **出错说清楚**：哪一格、为什么、允许什么范围。

## 4. 信息架构

### 4.1 区域划分

1. 页头：标题（含店铺）、编制任务与截止日期、单位状态徽章、保存状态
2. 单位信息条：店铺切换、站点、结算币种、预算汇率；新渠道时显示起始月与放量上限
3. 提示区：调整模式说明（仅目标调整）/ 已退回原因 / 已提交锁定 / 保存冲突 / 超范围错误列表 / 新渠道超放量
4. 关键数：全年收入（本币）、全年收入（人民币）、全年毛利、全年毛利率
5. 工具栏：填充全年、下载填报模板、上传填报文件；右侧「提交审核」
6. 调整原因（仅调整模式，必填）
7. 填报表格（主体）
8. 毛利计算引用的比例（可折叠，只读）

### 4.2 区域内容

**填报表格**
- 冻结左侧三列：品类、新/老品、项目；横向 1–12 月；最右「全年」列。
- 每个「品类 × 新老品」为一组：7 个输入行 + 5 个计算行。
- 底部「店铺合计」5 行；新渠道另有「超出理由」行。

## 5. 界面内容

### 5.1 元素清单

**店铺切换**
- 内容：当前用户被分配的店铺，格式「店铺 · 渠道 · 站点」，新渠道标「（新渠道）」。
- 数据来源：角色与数据范围（AC-F01-07）。原型：Amazon-US-01、TikTok-US-01。

**输入行（每组 7 行，AC-F04-01）**

| 项目 | 单位/格式 | 原型示例（Amazon-US-01 · 框镜 · 老品 · 1 月） |
| :--- | :--- | :--- |
| SPU 数量 | 整数 | 120 |
| 单 SPU 平均销量 | 件，1 位小数显示 | 52.0 |
| 平均单价（本币，列名带币种如 USD） | 2 位小数 | 89.99 |
| 折扣率 | 百分数，1 位小数 | 5.0% |
| 退款率 | 同上 | 5.0% |
| 广告费率 | 同上 | 8.0% |
| 佣金率 | 同上 | 15.0% |

**计算行（每组 5 行，只读，底色区分）**

| 项目 | 公式 | 依据 |
| :--- | :--- | :--- |
| 销量 | SPU 数量 × 单 SPU 平均销量 | AC-F06-01 |
| 收入（本币） | 销量 × 平均单价 × (1 − 折扣率) | AC-F06-01、AC-F06-08 |
| 收入（人民币） | 收入（本币）× 该币种 2027 预算汇率 | AC-F06-02、AC-F06-08 |
| 毛利（人民币） | 人民币收入 − 退款 − 采购成本 − 佣金 − 推广费用 − 头程 − 尾程 − 关税 − 仓储 + 库存索赔 − 其他运营费用；各项 = 人民币收入 × 对应比率 | AC-F06-03、AC-F06-04 |
| 毛利率 | 毛利 ÷ 人民币收入；人民币收入为 0 时显示「—」 | AC-F06-04 |

- 推广费用 = 人民币收入 × 广告费率；采购成本、头程、尾程、关税、仓储、库存索赔、其他运营费用的比率取自他人填报（见「毛利计算引用的比例」）。
- 金额四舍五入保留 2 位小数；合计行 = 明细行显示值之和（AC-F06-09）。
- 毛利为负时数字显示为不利色。

**店铺合计（5 行）**：销量、收入（本币）、收入（人民币）、毛利、毛利率，按月及全年。

**关键数**：全年收入（本币）显示「$ 20,226,117.07 USD」格式，全年收入（人民币）显示「¥ 144,009,953.51」格式（AC-F06-08）。

**新渠道信息（仅新渠道显示，AC-F13-02）**
- 文案：「新渠道 · 起始月 2027-03 · 放量上限按起始后第 1–12 个月逐月设定（人民币/店铺/月，规则库「新渠道月收入放量上限」v1 · 额度标准 · 未验证经验）」，规则名链接 PAGE-F12-01。
- 上限形式：规则库「额度标准」类规则，起始月后第 k 个月（k = 1–12）各有一个上限；起始月之前的月份不判断（DEC-F04-06）。原型 v1：180,000 / 240,000 / 300,000 / 360,000 / 420,000 / 480,000 / 520,000 / 540,000 / 660,000 / 720,000 / 780,000 / 840,000 元。
- 超放量月份：店铺合计「收入（人民币）」该月超过当月对应上限时，单元格红框，并在格内标注「超出新渠道放量规则」；悬停显示「起始后第 k 个月上限 ¥ x」。
- 汇总提示：「2 个月份超出新渠道放量规则：10月（第 8 个月，上限 ¥ 540,000.00）、11月（第 9 个月，上限 ¥ 660,000.00） 人民币收入超过当月上限。请在表格底部「超出理由」行逐月填写理由，未填写前不能提交。」

**调整模式（目标调整，DEC-F08-04）**
- 财务负责人在 PAGE-F08-01 发起季度目标调整后，填报人从「我的填报」或 PAGE-F08-01 进入本页，以「调整模式」打开。
- 页头副标题「2027 年第二季度目标调整 · 调整模式 · 截止 2027-05-20」；提示条「调整模式 · 2027 年第二季度目标调整 · 林晓 2027-04-20 发起，截止 2027-05-20。1–4 月已导入金蝶实际，不可修改；只能调整 5–12 月。提交时须填写调整原因，经运营部负责人赵磊、财务负责人林晓审核后，由 CEO 对整次调整一次性终审。」
- 已导入金蝶实际的月份表头标「（实际）」，输入单元格灰显不可编辑，悬停「已导入金蝶实际，不可调整」（AC-F08-02）。
- 「调整原因 *」多行输入；提交按钮为「提交调整」；原因为空提交时提示「请填写调整原因」（AC-F08-03）。
- 提交确认：「提交后依次由运营部负责人赵磊、财务负责人林晓审核；全部单位通过后，CEO 对整次调整一次性终审，通过即生成新的「调整后目标」版本，年初原始目标保持不变。被退回之前不能再修改。」（AC-F08-04）
- 「超出理由」行：仅超放量月份可编辑，空时显示「必填：超出理由」；其他月份显示「—」不可编辑。

**毛利计算引用的比例（折叠区，只读）**：按品类列出采购成本占比、头程费率、尾程费率、仓储费率、关税率；按渠道站点列出库存索赔率、其他运营费用率（原型各月取值相同）。

### 5.2 辅助信息

- 表格下方：「白底单元格可编辑：失焦即保存并刷新合计；Enter 下移，Esc 还原；可从 Excel 复制整块粘贴（按输入行顺序填入，跳过计算行）。比率按百分数录入，输入 15 即 15%。」
- 汇率旁注明「示例值，以财务BP录入为准」。

## 6. 交互流程

### 6.1 页面加载与初始化

- 校验当前用户对该店铺的数据权限；无权限显示「无权限」，不返回任何字段（AC-F01-11）。
- 加载已保存的驱动值、他人填报的比例、预算汇率，计算全部计算行与合计。
- 按单位状态决定可编辑性：填报中、已退回可编辑；已提交、已通过锁定。

### 6.2 核心操作流程

```
编辑单元格 → 失焦（或 Enter 下移 / Tab 右移）
    ├─ 内容未变 → 不保存
    ├─ 超出取值范围 → 拒绝保存：单元格红框，错误列表显示「字段 · 月份：输入「x」未保存，允许范围：…」；计算仍用上次保存值（AC-F04-02）
    └─ 合法 → 保存
         ├─ 该单元格在本人打开页面后已被他人保存 → 拒绝本次保存，提示「该数据已被 {姓名} 于 {时间} 修改，请刷新后再改」，提供「刷新」（AC-F04-10）
         └─ 保存成功 → 保存状态「正在保存…」→「已保存 · hh:mm:ss」→ 刷新计算行、店铺合计、关键数（NFR-001）；新渠道重新判断超放量月份

粘贴整块（Ctrl+V）
    → 从当前单元格起，按「输入行」顺序向下、按月向右填入，跳过计算行，超出 12 月或表格的部分丢弃（DEC-F04-04）
    → 每个单元格独立校验：合法的保存，不合法的标红不保存 → 轻提示「已粘贴 n 个单元格，其中 m 个超出取值范围未保存」

填充全年（AC-F04-06）
    → 弹窗选择「维度组合与比率」（默认当前聚焦的比率行）+ 输入比率
    → 校验 0%–100% → 写入该组合 12 个月中尚未提交的月份 → 刷新合计

提交审核
    ├─ 存在未保存的超范围单元格 → 阻止（DEC-F04-03）
    ├─ 涉及币种缺 2027 预算汇率 → 阻止并提示「2027 年度缺少以下币种的预算汇率：USD。请联系财务BP 在「汇率」中录入后再提交」（AC-F02-07）
    ├─ 新渠道超放量月份未填理由 → 阻止并列出月份（AC-F13-02）
    └─ 通过 → 确认弹窗「提交后状态变为「已提交」，并通知运营部负责人赵磊审核。被退回之前，你和其他人都不能再修改本单位内容。」→ 确认 → 状态「已提交」，全部单元格锁定（AC-F04-09）
```

### 6.3 Excel 模板

- 下载（AC-F04-07）：生成「{店铺}_2027年度预算填报模板.xlsx」，只含本人数据范围内的维度组合与本人负责的 7 个输入项，预填已保存的值。
- 上传（AC-F04-08）：选择 .xlsx → 校验 → 任一行不通过则整份不写入，弹窗列出全部错误「行号 / 字段 / 原因」，如：
  - 第 14 行 · 退款率 · 「105%」超出取值范围，允许范围：0% 到 100%
  - 第 27 行 · SPU 数量 · 「12.5」不是整数，允许范围：大于等于 0 的整数
  - 第 38 行 · 平均单价（USD）· 「-89.99」小于 0，允许范围：大于等于 0
  - 第 61 行 · 店铺 · 「Amazon-US-02」不在你的数据范围内
- 全部通过：写入并刷新合计，轻提示「校验通过，已写入 672 个单元格并刷新合计」。

### 6.4 辅助操作

- Enter：保存并移到下一输入行同月；Esc：还原为上次保存的值并清除红框。
- 切换店铺：保留各店铺已保存内容。

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 单元格清空 | 视为 0 保存（DEC-F04-02） |
| 输入带千分位、%、$、¥ | 自动去除后解析 |
| 人民币收入为 0 | 毛利率显示「—」（AC-F06-04） |
| 他人比例尚未填写 | 按 0% 计算，折叠区标「未填」 |
| 新渠道某月不再超放量 | 取消该月标注，理由单元格恢复「—」 |
| 截止日已过仍未提交 | 仍可填写和提交；逾期提醒由 F03 处理 |

## 8. 业务规则与校验

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 预算单元 | 月 × 渠道 × 店铺 × 站点 × 品类 × 新品/老品 |
| 预算汇率 | 该币种 2027 年度一币一值（AC-F02-06） |
| 放量上限 | 规则库「额度标准」类生效规则「新渠道月收入放量上限」的第 k 个月上限，k = 该月 − 起始月 + 1（REQ-F13-01、DEC-F04-06） |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| SPU 数量 | 失焦 / 粘贴 / 上传 | 大于等于 0 的整数（AC-F04-02） | 「允许范围：大于等于 0 的整数」 |
| 单 SPU 平均销量、平均单价 | 同上 | 大于等于 0；单价最多 2 位小数 | 「允许范围：大于等于 0」 |
| 折扣率、退款率、广告费率、佣金率 | 同上 | 0% 到 100% | 「允许范围：0% 到 100%」 |
| 非数字 | 同上 | — | 「请输入数字。允许范围：…」 |
| 并发保存 | 保存时 | 打开页面后该单元格未被他人保存（AC-F04-10） | 「该数据已被 {姓名} 于 {时间} 修改，请刷新后再改」 |
| 预算汇率 | 提交时 | 涉及币种均有 2027 预算汇率（AC-F02-07） | 提示缺少的币种代码 |
| 新渠道理由 | 提交时 | 超放量月份均已填理由（AC-F13-02） | 列出未填理由的月份 |
| 调整原因 | 调整模式提交时 | 非空（AC-F08-03） | 「请填写调整原因」 |
| 调整月份 | 调整模式编辑时 | 只能修改尚未导入金蝶实际的月份（AC-F08-02） | 单元格不可编辑 |
| 未保存错误 | 提交时 | 无红框单元格（DEC-F04-03） | 「仍有 n 个单元格超出取值范围未保存…」 |

### 8.3 特殊业务规则

- 提交后锁定，被退回前任何人不可修改（AC-F04-09）。
- 只返回本人被分配店铺的数据（AC-F01-07）。
