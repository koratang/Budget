## 2. 页面概述

### 2.1 一句话定位
逐板块填报业务驱动指标，分维度填报值自动聚合回指标整体值，再传导到财务指标。

### 2.2 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 不失真 | 未填报显示「—」，不以 0 拉低板块健康度（AC-F15-04） |
| 进度可见 | 说明卡显示「已填报 x / 31 项二级指标」「x / 76 个维度单元格」 |

### 2.3 不做什么
- **不做**供应链板块分品类矩阵、仓配履约分服务商矩阵——引擎 `DIM_SKIP_MAP` 跳过（S3 品类、S4 服务商），只能通过 PAGE-F15-09 维度导入。
- **不做**目标值的页内填报——本期矩阵均为「仅实际值」模式。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 财务BP 陈思雨（汇总运营、供应链台账后录入）、财务负责人 林晓、CEO 周明远（只读） |
| 频次 | 每月一次 |

**场景 A**：陈思雨在「营销板块 · 分渠道矩阵」的 Amazon × UV 格填 80.5，失焦后提示「S1.1 的渠道【Amazon】实际值已更新，指标整体值与板块达成率已同步重算」，S1.1 行出现「维度派生」徽标、输入框变为只读文本。
**场景 B**：示例数据下全部格为空，板块徽标为红色「待填报 0/13」。

## 4. 信息架构

1. 页头（外壳）：标题 +「示例数据」、描述「一级 / 二级业务指标体系 · 驱动因子与达成追踪」、年度 / 月度、期间
2. 说明卡：四板块与维度、数据状态、填报进度、导入入口
3. 按板块循环（S1 营销 → S2 产品 → S3 供应链 → S4 仓配履约）：板块明细卡 + 该板块的维度矩阵卡
4. 业务指标 → 财务指标 联动摘要

## 5. 界面内容

### 5.1 板块明细卡

| 元素 | 说明 |
| :--- | :--- |
| 标题 | 板块名 + 编码；右侧填报徽标：待填报 0/n（红）/ 填报中 x/n（琥珀）/ 已填报 n/n（绿） |
| 列 | 编码、指标名称（逆向 / 维度派生徽标）、单位、实际值、责任部门 |
| 实际值 | 编辑者为输入框（占位「—」）；已由维度聚合的指标显示文本并提示「请先清空维度矩阵中的填报值」 |
| 合计行 | 「板块合计」+「x / n 项二级已填报」+ 板块责任部门 |

板块二级数：S1 13 项、S2 3 项、S3 6 项、S4 9 项。

### 5.2 维度矩阵

| 矩阵 | 行（维度成员） | 列（指标） |
| :--- | :--- | :--- |
| 营销板块 · 分渠道 | Amazon / Wayfair / Home Depot / Lowe's / 独立站 | S1.1–S1.10（列头含编码、单位、逆向） |
| 产品板块 · 分品类 | 框镜 / 灯镜 / 镜柜 / 其他 | S2.1–S2.3 |
| 仓配履约板块 · 分线路区域 | 美东 / 美西 / 英国 / 欧洲 | S4.2 单位头程成本 |

单元格为「实际」输入框；末行「合计 / 均值」显示「整体值 x 单位」或「未填报 → 整体值待填报」；卡底说明聚合口径（加总型求和、比率型算术平均）。

### 5.3 联动摘要表
列：业务指标、传导至财务指标、方向（正向红 / 负向绿）、强度（条 + 百分比）、业务现状（已填报显示「实际 / 目标」，否则「待填报」）、责任部门；31 条按强度降序。

## 6. 交互流程

```
编辑维度单元格 → 引擎 editDimCell
  ├─ 非法值 → 回填 + 轻提示
  └─ 成功 → 若整体值随之变化 commit(['biz_dim','indicators']) 否则 commit('biz_dim') → 「保存中…」
编辑指标实际值 → editCell → commit('indicators')（月度维度写当月覆盖并反算年度）
409 冲突 → 红色条「「业务指标维度填报」已被某某更新，请刷新后再改。…」+「刷新数据」
```

## 7. 状态与边界

| 状态 | 页面表现 |
| :--- | :--- |
| 加载 / 错误 / 无权限 | 同外壳：骨架；「业财分析数据加载失败」+「重试」；403 无权限 +「返回工作台」 |
| CEO 只读 | 输入框全部替换为文本，空值显示「—」 |
| 维度值清空 | 提示「…已清空（该指标整体值将与维度填报值重新聚合）」 |
