## 2. 页面概述

### 2.1 一句话定位
让管理层在一页内看清三项成功指标：累计净利润达成率（原始 / 调整后两个口径）、部门费用是否比收入涨得快、季度预测准不准。

### 2.2 存在理由
1. 北极星指标「净利润达成率（按年初原始目标）」需要一个固定看的地方（PRD §6.1）。
2. 目标每季度可调整，只看调整后目标会掩盖与原始目标的差距，所以必须双口径并列（AC-F10-08）。
3. 部门费用增速超过收入增速、预测偏差超过 1.5 个百分点都是需要立即追问的信号（AC-F10-09、AC-F10-10）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 双口径 | 两个达成率同屏显示，分母各自注明版本 |
| 异常识别 | 部门费用增速 > 收入增速、预测偏差 > 1.5 个百分点 100% 标红 |
| 可导出 | 导出列与页面显示一致（AC-F14-01） |

### 2.4 不做什么
- **不做**净利润的渠道 / 部门拆解——分别在 PAGE-F10-02、PAGE-F10-04。
- **不做**月份或版本选择——AC-F10-08 固定为「截至最近导入月」，口径固定为原始与最新调整后。
- **不做**预警配置——属于 PAGE-F12-01 规则库。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | CEO 周明远、财务负责人 林晓、财务BP 陈思雨 |
| 使用设备 | 公司电脑 / 钉钉内置浏览器 |
| 频次 | 每月金蝶导入后（约次月第 18 个工作日）查看；月度复盘会投屏 |

### 3.2 核心场景
**场景 A：月度复盘**——金蝶 4 月实际导入后，林晓打开公司汇总，看到原始口径 88.0%、调整后口径 91.5%；部门费用增速 +16.0% 高于收入增速 +11.9%，标红；4 月预测偏差 1.8 个百分点，标红。她点「查看部门费用报告」追到市场部展会费超支。
**场景 B：汇报材料**——财务BP 点「导出 Excel」生成三个工作表，贴进月度会材料。

## 4. 信息架构

1. 页头：标题、截至期间说明、「导出 Excel」

## 5. 界面内容

### 5.1 元素清单

**页头说明**：「截至 2027-04（最近金蝶导入期间）· 预算年度 2027 · 金额单位：人民币元」。截至月份 = 最近一次金蝶导入的期间。

**净利润达成率卡片 ×2（AC-F10-08）**
- 左：按年初原始目标；徽章写版本名「V1 年初原始目标」。
- 右：按最新调整后目标；徽章写版本名与生效日，如「V2 2027Q2 目标调整（2027-04-08 生效）」。本年度无调整时徽章写「本年度暂无调整，按年初原始目标」，数值与左卡相同。
- 数值 = 年初至最近导入月实际净利润合计 ÷ 同期目标净利润合计（Σ1 月至截至月），保留 1 位小数；同期目标合计 ≤ 0 时显示「—」且不画达成条（AC-F10-08）。
- 卡片底部口径说明：「口径：年初至最近导入月实际净利润合计 ÷ 同期目标净利润合计；同期目标合计 ≤ 0 时显示「—」」。
- 下方一行：累计实际 ¥ … ÷ 累计目标 ¥ …。
- 达成条：累计对累计，刻度线 = 100%；按收入类规则着色（低于 90% 琥珀，低于 70% 红，其余深灰）。

**净利润按月构成表**：月份｜年初原始目标净利润｜最新调整后目标净利润｜实际净利润｜达成率（原始）｜达成率（调整后）｜达成条（调整后）；末行「1–N 月累计」。达成率 < 100% 红，≥ 100% 绿。

**部门费用增速 vs 收入增速（AC-F10-09）**
- 三张数字卡：收入合计增速、部门费用合计增速、两者之差（个百分点）。
- 部门费用增速 > 收入增速时：部门费用增速与差值标红，差值卡下注「部门费用增长快于收入」；否则差值为绿，注「部门费用增长未快于收入」。
- 明细表：项目｜上年同期实际｜本年累计实际｜增额｜增速｜明细链接（收入→PAGE-F10-02，部门费用→PAGE-F10-04）。
- 增速 = (本年 1–N 月实际 − 上年 1–N 月实际) ÷ 上年 1–N 月实际。部门费用合计与 PAGE-F10-04「全公司合计」累计实际一致。

**季度预测准确度（AC-F10-10）**
- 表：月份｜所属季度快照（如「Q1 快照 · 2027-01-04」）｜快照预测净利润率｜实际净利润率｜偏差（百分点）｜判定徽章（超阈值 红 / 未超）。
- 偏差 = |快照预测净利润率 − 实际净利润率|；净利润率 = 净利润 ÷ 人民币收入；按未四舍五入值与 1.5 比较，等于 1.5 不标红。
- 已有快照但金蝶实际未导入的月份显示「实际未导入」「待金蝶实际」；所属季度没有已发布快照的月份不显示该行（不满足 AC-F10-10 前提）。
- 柱状图：各月偏差，纵轴 0–2.5 个百分点统一比例尺，1.5 处画红色虚线阈值，超阈值柱为红色。

**导出 Excel**：见 §8.3。

## 6. 交互流程

### 6.1 加载
进入页面 → 按当前用户数据范围请求汇总数据 → 显示骨架 → 渲染。非全公司范围角色直接显示无权限（服务端同样拒绝，NFR-003）。

### 6.2 核心流程
```
打开公司汇总
  ├─ 无权限角色 → 无权限态
  ├─ 本年度无金蝶实际 → 空态
  └─ 有实际 → 渲染双口径、增速、准确度
        ├─ 上年同期未导入 → 增速区显示「上年同期实际未导入，暂不计算增速」
        └─ 点「导出 Excel」→ 按钮「正在导出…」→ 下载 .xlsx → 轻提示
```

## 7. 状态与边界

### 7.1 页面状态

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有至少一个月金蝶实际 | 全部区块 |
| 空 | 本年度没有任何金蝶实际 | 「2027 年还没有导入金蝶实际」；财务BP 见「去导入实际数」→ PAGE-F09-01 |
| 加载 | 请求中 | 两张卡片与表格骨架；导出按钮禁用 |
| 错误 | 请求失败 | 「公司汇总加载失败」+「重试」 |
| 无权限 | 非 CEO / 财务负责人 / 财务BP | 「无权限」说明 +「返回工作台」；侧栏不显示本菜单 |

### 7.2 边界

| 场景 | 处理 |
| :--- | :--- |
| 上年同期实际未导入 | 增速区替换为提示；财务BP 见「去做历史导入」→ PAGE-F09-01 |
| 本年无目标调整 | 调整后口径 = 原始口径，徽章说明 |
| 某月所属季度无快照 | 该月不进入准确度表 |
| 目标净利润为 0 或负数 | 同期目标合计 ≤ 0：卡片与累计行显示「—」；单月目标 ≤ 0：该月达成率显示「—」（AC-F10-08） |

## 8. 业务规则

### 8.1 字段定义

| 字段 | 说明 |
| :--- | :--- |
| 实际净利润 | 全部平台渠道毛利 + 全部 B 端毛利 − 全部部门费用 + 公司层其他损益（AC-F06-07） |
| 年初原始目标 | CEO 审批锁定的 V1 版本 |
| 最新调整后目标 | 最近一次审批通过的季度目标调整版本 |
| 快照 | 季度滚动预测发布时保存的不可修改版本；Q1 可用年初原始目标发布 |

### 8.2 着色规则
- 不利红、有利绿；预警琥珀只用于达成条。
- 金额 2 位小数千分位，百分比 1 位小数，数字右对齐等宽。

### 8.3 导出（AC-F14-01）
- 生成 .xlsx，文件名「公司汇总_截至YYYY-MM.xlsx」，三个工作表：净利润（按月构成表）、增速对比（明细表）、预测准确度（逐月表），列与页面一致。
- 只对有本页权限的全公司范围角色开放；服务端按数据范围过滤（NFR-003）。

## 10. 数据需求

| 数据 | 来源 | 用途 |
| :--- | :--- | :--- |
| 1–N 月实际净利润、人民币收入 | 金蝶导入 + 计算 | 达成率、净利润率、收入增速 |
