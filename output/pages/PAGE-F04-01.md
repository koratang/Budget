## 2. 页面概述

### 2.1 一句话定位

填报人的入口：一眼看到自己负责哪些单位、哪些还没交、哪些被退回以及原因。

### 2.2 存在理由

1. 运营王浩一人负责 5 个店铺，需要集中入口（US-F04-01）。
2. 提交后锁定、退回后解锁，填报人要知道当前能不能改（AC-F04-09、AC-F07-03）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 找到入口 | 从本页 1 次点击进入任一单位的填报页 |
| 状态清楚 | 每个单位显示状态；已退回显示原因；已提交显示已锁定 |

### 2.4 不做什么

- 不在本页编辑数值——进入对应填报页。
- 不显示他人负责的单位。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 运营王浩（5 个店铺）、B端业务孙婷（B端 · 美国业务部 + 美国业务部部门费用）、财务BP陈思雨（成本比例 + 财务部部门费用）、物流物控蒋帆（物流比例 + 物流物控部部门费用）、部门预算专员郑可（人力资源部） |

**主场景**：收到钉钉通知 → 打开本页 → 按顺序处理已退回、未开始、填报中的单位。

## 4. 信息架构

1. 页头：标题、汇总「你负责 5 个填报单位，待处理 3 个（未开始、填报中或已退回）。」
2. 逾期提示：「已过截止日期 2026-12-20 · 还有 3 个单位未提交，请尽快完成。」
3. 单位列表（已退回排最前，其次未开始、填报中、已提交、已通过）
4. 页脚说明：「已提交、已通过的单位内容已锁定，被退回之前任何人都不能修改，只能查看。」

## 6. 交互流程

- 进入页面 → 按当前用户的数据范围加载其作为填报人的单位 → 排序展示。
- 填报单位按 AC-F03-05 划分：运营每个负责的启用店铺一个、B端业务所在负责部门一个、财务BP 成本比例一个、物流物控物流比例一个、部门预算专员本部门的部门费用一个。
- 目标调整或滚动更新进行中时，对应单位同样列在本页（「任务」列显示如「2027 年第二季度目标调整」），进入后填报页以「调整模式」打开，只能编辑未导入实际的月份（DEC-F08-04）。原型展示编制期场景。
- 点击操作 → 进入对应填报页；已提交、已通过进入只读状态（AC-F04-09）。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 进入页面 | 骨架行「正在加载我的填报…」 |
| 空 | 没有进行中的编制任务或本人未被列为填报人 | 「你目前没有需要填报的单位」「财务负责人发布编制任务后，你负责的填报单位会出现在这里，同时你会收到钉钉工作通知。」 |
| 错误 | 网络或服务异常 | 「我的填报加载失败」+「重试」 |
| 无权限 | 账号没有任何填报角色 | 「无权限」「你的账号没有任何填报角色。如需填报，请联系财务负责人分配。」 |
| 全部已提交 | 无待处理单位 | 不显示逾期提示 |

## 8. 业务规则与校验

- 提交后状态为已提交，被退回之前任何人不能修改该单位内容（AC-F04-09）。
- 逾期：截止日期已过且状态不是已提交或已通过（AC-F03-04）。
