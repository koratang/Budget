## 2. 页面概述

### 2.1 一句话定位

财务负责人在这里决定「谁能进系统、以什么角色、看到哪些部门 / 店铺 / 客户」。

### 2.2 存在理由

1. 登录准入以「至少一个角色」为条件（AC-F01-01、AC-F01-02），角色只能在此分配。
2. 行级数据权限依赖每人的范围设置（REQ-F01-03），没有范围就无法做服务端过滤（NFR-003）。

### 2.3 不做什么

- 不做自定义角色或逐功能授权：角色固定为 PRD §2.1 的 8 类。
- 不做审计日志查看：每次保存会留痕（NFR-004），本期不提供查看页（蓝图 §9）。
- 不新增或停用员工：员工与账号状态来自钉钉通讯录。

## 3. 用户与场景

- **场景 A：编制前批量开通**：编制任务发布前，财务负责人逐个为 15 个部门的负责人、预算专员、运营、B端业务等分配角色与范围。
- **场景 B：人员变动**：运营调整负责渠道 → 修改其店铺范围 → 保存后对方下一次打开页面即按新范围看到数据（AC-F01-04）。
- **场景 C：撤销权限**：员工转岗不再参与预算 → 撤销全部角色 → 对方下一次请求被拒（AC-F01-02）。

## 4. 信息架构

1. 页头：标题 + 说明「员工来自钉钉通讯录 · 保存后对方下一次打开页面即按新范围生效」
2. 筛选栏：姓名搜索、钉钉部门、角色、「只看未分配角色」
3. 员工列表 + 分页（每页 50 条）
4. 分配抽屉（右侧）：角色多选 → 按所选角色出现对应范围区 → 保存 / 取消 / 撤销全部角色
5. 撤销确认弹窗

## 5. 界面内容

### 5.1 员工列表字段

| 列 | 内容 | 来源 |
| :--- | :--- | :--- |
| 姓名 | 钉钉姓名 | 钉钉通讯录 |
| 钉钉部门 | 员工在钉钉中的部门 | 钉钉通讯录 |
| 角色 | 角色徽章，可多个；无角色显示「未分配」 | 本系统 |
| 数据范围 | 摘要：全公司 / 部门：… / 店铺：…（整渠道显示「Amazon（全部 4 个店铺）」）/ 客户：… / 物流比例四项；过长截断，悬停显示全文 | 本系统 |
| 钉钉账号 | 正常 / 已停用（停用或移出通讯录） | 钉钉通讯录 |
| 操作 | 「分配」；账号已停用时显示「账号停用，无法登录」不可分配 | — |

列表底部：「共 N 名员工 · 已分配角色 X 人 · 未分配 Y 人」。

### 5.2 分配抽屉

| 区域 | 内容 | 显示条件 |
| :--- | :--- | :--- |
| 标题 | 「分配角色 · {姓名}」+ 钉钉部门 | 始终 |
| 角色（可多选） | CEO、财务负责人、财务BP、运营、B端业务、物流物控、部门负责人、部门预算专员 | 始终 |
| 全公司说明 | 「CEO、财务负责人、财务BP 查看全公司全部部门、渠道和 B端客户，无需设置范围」（AC-F01-10） | 选了 CEO / 财务负责人 / 财务BP |
| 部门范围 * | 15 个部门多选；说明「只见所选部门的费用预算、实际与报表」（AC-F01-06） | 选了部门负责人或部门预算专员 |
| 渠道 / 店铺范围 * | 渠道 → 店铺两级勾选，勾渠道即全选其店铺（AC-F01-07） | 选了运营 |
| B端客户范围 * | 客户多选，显示负责部门与币种（AC-F01-08） | 选了 B端业务 |
| 物流物控说明 | 「只展示并允许编辑头程费率、尾程费率、仓储费率、关税率四项及其渠道 / 站点 / 品类维度，不展示收入金额与利润」（AC-F01-09） | 选了物流物控 |
| 按钮 | 撤销全部角色（仅已有角色时）、取消、保存 | — |
| 保留财务负责人校验 | 「系统至少保留一位财务负责人：请先为其他员工分配「财务负责人」，再撤销此人的财务负责人角色」 | 保存时去掉最后一位财务负责人的该角色，或对其点「撤销全部角色」（DEC-F01-05） |

渠道、店铺、客户选项来自 `PAGE-F02-01.html`、`PAGE-F02-03.html` 的基础数据；部门来自部门清单。

## 6. 交互流程

```
点「分配」→ 打开抽屉（带出现有角色与范围）
  → 勾选角色 → 对应范围区出现 / 隐藏
  → 点「保存」
       ├─ 未选任何角色 → 「请至少选择一个角色；如需取消此人的全部权限，请点「撤销全部角色」」
       ├─ 需要范围的角色未选范围 → 对应区域标红 + 「请选择至少一个部门 / 渠道或店铺 / B端客户」
       └─ 通过 → 保存并记录审计（NFR-004）→ 关闭抽屉 → 轻提示「已保存。{姓名} 下一次打开页面时按新角色和范围生效」→ 列表刷新
点「撤销全部角色」→ 确认弹窗「撤销后，{姓名} 下一次打开页面或登录时将看到「未开通预算权限，请联系财务负责人」，无法再查看任何预算数据。」→ 确认撤销 → 轻提示
```

- 抽屉内按 Esc 或点击遮罩 = 取消，不保存。
- 筛选即时生效。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 读到通讯录员工 | 列表 |
| 空 | 通讯录尚未同步到任何员工 | 「还没有读到钉钉通讯录员工」+ 说明 +「重新同步通讯录」 |
| 筛选无结果 | 筛选条件无匹配 | 表内「没有符合条件的员工 · 调整筛选条件后再试」 |
| 加载 | 请求中 | 骨架行 |
| 错误 | 通讯录读取失败 | 「员工列表加载失败 · 钉钉通讯录暂时无法读取，请稍后重试」+ 重试 |
| 无权限 | 非财务负责人打开（含直接输入链接） | 「无权限」+「角色分配仅财务负责人可用」+ 返回工作台；不返回任何员工数据（AC-F01-05、AC-F01-11） |

| 边界 | 处理 |
| :--- | :--- |
| 员工钉钉账号停用 | 列表标「已停用」，不可分配；其登录与会话按 AC-F01-03 处理 |
| 对方正在使用系统时被修改 | 下一次页面请求即按新范围返回数据（AC-F01-04） |
| 停用的店铺 | 仍可出现在范围选项中（历史实际仍会导入，AC-F02-10），标「已停用」 |
| 系统初次部署 | 第一个财务负责人由部署配置指定（DEC-F01-04） |
| 撤销最后一位财务负责人 | 阻止并提示，系统至少保留一位（DEC-F01-05） |

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 角色 | 保存时 | 至少 1 个 | 见 §6 |
| 部门范围 | 保存时 | 选了部门负责人 / 部门预算专员时至少 1 个部门 | 「请选择至少一个部门」 |
| 渠道 / 店铺范围 | 保存时 | 选了运营时至少 1 个 | 「请选择至少一个渠道或店铺」 |
| B端客户范围 | 保存时 | 选了 B端业务时至少 1 个 | 「请选择至少一个 B端客户」 |

- 数据范围由服务端过滤，越权请求返回「无权限」且不含记录字段（NFR-003、AC-F01-11）。
- 角色分配的每次修改记录操作人、时间、修改前后值，保留 ≥ 3 年，任何角色不能删除（NFR-004）。

## 9. 页面流转

```
侧栏「角色与权限」→ 本页（财务负责人）──分配抽屉──→ 保存 → 本页
其他角色 → 本页 → 「无权限」→ PAGE-F00-01 · 工作台
```
