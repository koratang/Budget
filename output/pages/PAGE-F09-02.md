## 2. 页面概述

### 2.1 一句话定位

把同一个月 BI 的销售额（折人民币）和金蝶收入按店铺 × 站点逐一对上，差异超过 3% 的标红，先查清再用于偏差分析。

### 2.2 存在理由

1. BI 是 SKU 级、金蝶是财务口径，两者不一致会让品类分析和收入偏差互相矛盾（AC-F09-07）。
2. 财务BP 需要一眼找到差异大的组合去追查（导入遗漏、退款口径、汇率）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 覆盖 | 两边都已导入的月份，每个店铺 × 站点组合都有一行 |
| 标识准确 | 差异率绝对值 > 3% 的组合 100% 标红，≤ 3% 不标 |

### 2.4 不做什么

- 不自动修正任一侧数据，不做差异说明录入（偏差说明在 F10 报表）。
- 不核对 B端客户（BI 只含平台店铺）。

## 3. 用户与场景

**场景 A：导入后核对**：陈思雨 2027-05-12 补录 2027-04 GBP 当月平均汇率后选 2027-04 → 9 个组合中 3 个标红（Amazon-UK-01 +3.9%、HomeDepot-US-01 −3.6%、TikTok-US-01 −3.4%）；若某币种当月平均汇率未录入，该组合提示「缺少 YYYY-MM 币种 当月平均汇率」并链接汇率页、不计入核对→ 勾选「只看差异率超过 3%」聚焦 → 去渠道×站点偏差查看收入明细或回导入页核对源文件。

**场景 B：月份未齐**：选 2027-05 → 提示金蝶 2027-05 未导入、BI 最近截至 2027-04，无法核对。

## 4. 信息架构

1. 筛选行：月份、渠道、「只看差异率超过 3%」、导出 Excel
2. 关键数：核对组合数、差异率绝对值超过 3% 的组合数、BI 折人民币合计、金蝶收入合计
3. 口径说明：差异率公式（分母为金蝶收入）、所用当月平均汇率（4 位小数）
4. 核对表
5. 后续动作链接

## 5. 界面内容

| 列 | 内容 |
| :--- | :--- |
| 店铺 · 站点 | 主文字；渠道小字 |
| BI 本币销售额 | 「$ 1,543,820.00 USD」格式 |
| 当月平均汇率 | 该币种该月当月平均汇率，4 位小数（AC-F02-08、DEC-F02-09）；未录入时显示「未录入」 |
| BI 折人民币 | ¥ 千分位 2 位小数 |
| 金蝶收入 | ¥ 千分位 2 位小数 |
| 差额 | BI 折人民币 − 金蝶收入，带正负号 |
| 差异率 | 带正负号 1 位小数；绝对值 > 3% 时不利色 |
| 标记 | 超 3% 显示「超过 3%」不利色徽章，整行浅红底；缺汇率时显示「缺少 YYYY-MM 币种 当月平均汇率」链接 `PAGE-F02-05.html`，该组合不计入核对数 |

数字列全部等宽右对齐。新渠道在起始月（TikTok Shop 2027-03）之前的月份不出现。

## 6. 交互流程

```
选择月份
  ├─ BI 与金蝶都已导入 → 按 月×店铺×站点 计算差异率并标红（AC-F09-07）
  └─ 任一侧未导入 → 说明哪一侧缺失 + 「去导入实际数」
筛选渠道 / 只看超 3% → 即时过滤；关键数始终按全月统计
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 所选月两侧均已导入 | 关键数 + 表格 |
| 所选月未齐 | 任一侧未导入 | 「2027-05 还不能核对」+ 原因 + 去导入 |
| 筛选无结果 | 只看超 3% 但无 | 「没有差异率超过 3% 的组合」 |
| 空 | 没有任何月份两侧都导入 | 「还没有可核对的月份」+ 去导入 |
| 加载 | 请求中 | 骨架行 |
| 错误 | 请求失败 | 「数据加载失败」+ 重试 |
| 无权限 | 非财务BP / 财务负责人 / CEO | 无权限提示 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 恰好 3.0% | 不标红（规则为「超过 3%」） |
| 金蝶收入为 0 而 BI 有销售额 | 差异率显示「—」，整行标红并注明「金蝶无收入」（DEC-F09-02） |
| 缺当月平均汇率 | 不计算 BI 折人民币与差异率，提示补录（DEC-F02-09） |

## 8. 业务规则与校验

- 差异率 = (BI 销售额折人民币 − 金蝶收入) ÷ 金蝶收入；|差异率| > 3% 标红（AC-F09-07）。
- BI 本币销售额按该月当月平均汇率折算为人民币（AC-F09-07、AC-F02-08）。
