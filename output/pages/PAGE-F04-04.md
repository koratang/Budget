## 2. 页面概述

### 2.1 一句话定位

让财务BP 一处填完毛利所需的采购成本、库存索赔、其他运营费用比例，以及不分摊的公司层其他损益。

### 2.2 存在理由

1. 运营与 B 端只填收入驱动，毛利缺采购成本等比例就算不出来（US-F04-03）。
2. 财务费用、汇兑损益、营业外收支、所得税只在公司层计入净利润，不能分摊（AC-F06-06）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 覆盖 | 9 个渠道站点 × 4 品类、3 个 B 端客户、9 个渠道站点 × 2 项、4 项其他损益，全部 12 个月可填 |
| 效率 | 同一比例全年相同时一次「填充全年」完成 |

### 2.4 不做什么

- 不填物流四项比例（PAGE-F04-05）。
- 采购成本占比不细到店铺和新老品——需求维度为「渠道 × 站点 × 品类」。
- 不显示各渠道收入与毛利结果——本页只录比例；结果在填报页与报表查看。

## 3. 用户与场景

| 维度 | 描述 |

**主场景**：切换标签 → 填写或粘贴 → 「填充全年」批量写入 → 提交给财务负责人审核。

## 5. 界面内容

### 5.1 元素清单

**标签 1：采购成本占比 · 平台（AC-F04-04）**
- 冻结列：渠道、站点、品类；1–12 月；每格一个百分数。
- 维度说明：「维度：月 × 渠道 × 站点 × 品类。同一渠道站点品类下的新品、老品共用该比例。」
- 渠道站点：Amazon（美国、加拿大、英国、德国）、Wayfair 美国、Home Depot 美国、Lowe's 美国、独立站 美国、TikTok Shop 美国；品类：框镜、灯镜、镜柜、浴室门。示例：Amazon · 美国 · 框镜 27.0%。

**标签 2：采购成本占比 · B端客户（AC-F04-04）**
- 冻结列：B 端客户、负责部门。示例：Ferguson 50.0%、Menards 52.0%、Bauhaus 48.0%。

**标签 3：库存索赔率与其他运营费用率（AC-F04-11）**
- 冻结列：渠道、站点、项目；每个渠道站点两行。
- 说明：「该比例适用于该渠道站点下全部品类和新老品单元。」示例：Amazon · 美国 库存索赔率 0.3%、其他运营费用率 1.5%。

**标签 4：公司层其他损益（AC-F06-06）**
- 行：财务费用、汇兑损益、营业外收支、所得税；末行「其他损益合计」；右侧「全年合计」列。
- 金额为人民币，2 位小数。说明：「计入公司净利润，不分摊到任何渠道、品类或部门。收益填正数，损失或支出填负数（如财务费用 −85,000.00）。」（AC-F06-07）
- 示例月值：财务费用 −85,000.00、汇兑损益 −20,000.00、营业外收支 −5,000.00、所得税 −300,000.00，合计 −410,000.00。负数显示为不利色。

表格下方说明同 PAGE-F04-02（失焦保存、Enter、Esc、整块粘贴、百分数录入）。

### 调整模式（目标调整，DEC-F08-04）

财务负责人在 PAGE-F08-01 发起季度目标调整后，填报人从「我的填报」进入本页，以「调整模式」打开（与 PAGE-F04-02 相同）：
- 页头副标题改为「2027 年第二季度目标调整 · 调整模式 · 截止 2027-05-20」，显示调整提示条「1–4 月已导入金蝶实际，不可修改；只能调整 5–12 月。提交时须填写调整原因，经部门负责人、财务负责人审核后，由 CEO 对整次调整一次性终审。」
- 已导入金蝶实际的月份表头标「（实际）」，输入单元格灰显不可编辑（AC-F08-02）；「填充全年」只写入可编辑月份。
- 「调整原因 *」必填，为空提交时提示「请填写调整原因」（AC-F08-03）；提交按钮为「提交调整」，确认弹窗说明部门负责人 → 财务负责人逐个审核、CEO 整次终审（AC-F08-04）。

## 6. 交互流程

- 单元格编辑、粘贴、保存冲突、模板、提交与锁定：沿用 PAGE-F04-02 §6。
- 填充全年（AC-F04-06）：弹窗下拉列出当前标签全部比率行（如「Amazon · 美国 · 浴室门 · 采购成本占比」），输入比率后写入 12 个尚未提交的月份。
- 渠道筛选：只影响平台类标签的行显示，不影响数据。
- 模板：一个文件四个工作表，与四个标签对应，预填已保存值。上传错误示例：第 18 行 · 采购成本占比 ·「127%」超出取值范围；第 42 行 · 站点 ·「日本」不在渠道与店铺基础数据中，请先在「渠道与店铺」中添加；第 7 行 · 财务费用 ·「八万五」不是数字。
- 提交：通知财务负责人林晓审核。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 进入页面 | 骨架行「正在加载成本比例…」 |
| 空 | 无进行中编制任务或本单位未纳入任务 | 「暂无需要填报的成本比例」+「返回我的填报」 |
| 错误 | 网络或服务异常 | 「成本比例加载失败」+「重试」 |
| 无权限 | 非财务BP 访问 | 「无权限」「成本比例只由财务BP 填报。如需开通，请联系财务负责人。」 |
| 已退回 / 已提交 / 保存冲突 | 同 PAGE-F04-02 | 同 PAGE-F04-02 |

| 边界场景 | 处理策略 |
| :--- | :--- |
| 新增渠道站点（如 TikTok Shop 美国） | 基础数据启用后自动出现新行，初值为空（按 0% 计算） |
| 其他损益填正数 | 视为收益，合法 |

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 各比率 | 失焦 / 粘贴 / 上传 / 填充全年 | 0% 到 100% | 「允许范围：0% 到 100%」 |
| 其他损益金额 | 同上 | 任意数字，最多 2 位小数；损失或支出填负数 | 「允许范围：任意金额（损失或支出填负数），最多 2 位小数」 |

- 采购成本 = 人民币收入 × 采购成本占比；库存索赔、其他运营费用同理（AC-F06-03）。
- 公司净利润 = 平台毛利合计 + B 端毛利合计 − 部门费用合计 + 公司层其他损益（AC-F06-07）。
