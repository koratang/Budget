## 2. 页面概述

### 2.1 一句话定位
按店铺站点逐行看清当月收入、各项费用和毛利差在哪里，以及收入差是由量、价还是汇率造成的。

### 2.2 存在理由
1. 渠道×站点是预算最主要的经营单元，没有逐行对比就无法定位偏差（US-F10-01）。
2. 只看金额差分不清是卖少了、卖便宜了还是汇率变了，决策会用错手段（REQ-F10-02）。
3. 没有店铺核算的成本若混进店铺会让渠道毛利失真，必须单列（PRD §3.3.9）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 覆盖 | 每月 100% 渠道×站点有对比（PRD §6.2） |
| 拆分正确 | 量差 + 价差 + 汇率差 + 口径差 = 金蝶实际收入 − 预算收入（误差 ≤ 0.01 元/项） |
| 权限 | 运营只看到负责渠道的行 |

### 2.4 不做什么
- **不做** B 端客户的量价拆分——B 端没有 BI 销量数据，只看金额差与费率差。
- **不做**说明的审批或多级评论——AC-F10-11 只要求财务BP填写、有权限者可见。
- **不做**公共费用分摊——PRD 已决定不分摊（OQ-8）。

| 维度 | 描述 |

### 5.2 主表列（AC-F10-02）

| 分组 | 列 |
| :--- | :--- |
| 维度（冻结） | 店铺（新渠道带「新渠道」徽章）、渠道、站点 |
| 收入 | 预算、实际、实际（本币，带币种代码，AC-F06-08）、差额、达成率、达成条 |
| 收入差额拆分 | 量差、价差、汇率差、口径差（BI 未到时整组隐藏） |
| 毛利 | 预算、实际、差额、达成率 |
| 毛利率 | 预算、实际、差（百分点） |
| 偏差说明 | 说明首行 + 填写人 · 填写时间 + 「查看全文 / 查看/编辑」；无说明时财务BP 见「填写说明」，其他人见「—」 |

- 差额 = 实际 − 预算；达成率 = 实际 ÷ 预算；毛利率显示百分点差。
- **未归属渠道行**：只有实际（金蝶无店铺核算的成本费用），预算、差额、达成率显示「—」，毛利列显示其对毛利的影响（负数）。只对全公司范围角色显示，渠道筛选为「全部」时出现。
- **B 端分组（AC-F10-12）**：分组标题行「B 端（按客户）」，其下每个客户一行：店铺列为客户名、渠道列为「B 端 · 负责部门」、站点「—」；收入（预算 = 本币销售额 × 预算汇率，实际 = 金蝶收入）、毛利、毛利率的预算 / 实际 / 差额 / 达成率；实际（本币）列「—」；拆分列合并显示「B 端不做量价拆分」；展开明细含退款与各项费用的预算、实际、差额、达成率与费率差。
- **合计行**：全公司范围角色为「合计（含 B 端与未归属渠道）」；运营或筛选了渠道时为「合计（当前范围）」。
- **缺当月平均汇率**：该店铺汇率差显示「缺少 YYYY-MM 汇率」，口径差「—」；合计行同样显示（DEC-F02-09）。
- 新渠道起始月之前的月份不出现该店铺行（如 TikTok-US-01 起始 2027-03）。

### 5.3 展开明细
**明细表**：项目｜预算｜实际｜差额｜达成率｜达成条｜预算费率｜实际费率｜费率差。
- 项目顺序：收入（下方小字显示预算本币、实际本币）、退款、采购成本、佣金、推广费用、头程费、尾程费、关税、仓储费、库存索赔、其他运营费用、毛利（AC-F06-03、AC-F06-04）。
- 费率差 = (实际费率 − 预算费率) × 实际人民币收入；实际费率 = 实际费用 ÷ 实际人民币收入（AC-F10-04）。

**收入差额拆分卡（AC-F10-03）**：列出预算销量 × 预算净单价、实际销量 × 实际净单价、预算汇率 / 当月平均汇率、量差、价差、汇率差、口径差（单列一行）、收入差额，以及公式说明：
- 量差 = (实际销量 − 预算销量) × 预算净单价 × 预算汇率
- 价差 = (实际净单价 − 预算净单价) × 实际销量 × 预算汇率
- 汇率差 = 实际本币收入 × (当月平均汇率 − 预算汇率)
- 口径差 = 金蝶实际收入 − BI 本币收入 × 当月平均汇率（DEC-F10-02）
- 净单价 = 平均单价 × (1 − 折扣率)；实际净单价 = BI 本币销售额 ÷ BI 销量
- 量差 + 价差 + 汇率差 + 口径差 = 收入差额（金蝶实际 − 预算人民币收入）。口径差不为 0 时，卡片底部提示「口径差来自金蝶收入与 BI 收入不一致，见 BI 与金蝶核对」→ `PAGE-F09-02.html`；缺当月平均汇率时提示补录 → `PAGE-F02-05.html`。
- B 端客户行的卡片说明「B 端客户没有 BI 销量数据，不做量价拆分，只看金额差异与费率差。实际收入与费用取自金蝶。」

**样例核算（2027-04，最新调整后目标，Amazon-US-01）**：预算 26,400 件 × 64.3080 美元 × 7.12 = 12,087,846.14；实际 23,480 件，本币 1,523,860.40 美元 × 当月平均汇率 7.1980 = 10,968,747.16（与金蝶收入一致，口径差 0.00）。量差 −1,336,989.04 + 价差 +99,028.95 + 汇率差 +118,861.11 + 口径差 0.00 = −1,119,098.98 = 收入差额。Wayfair-US-01 金蝶收入比 BI 折人民币多 42,259.52，单列为口径差。原型中所有行由同一套公式实时计算。

### 5.4 BI 未导入（AC-F10-05）
该月 BI 实际尚未导入时：表格上方与拆分卡显示「量价拆分待 BI 数据（最近 BI 数据截至 YYYY-MM）」；拆分区域整体隐藏——主表「收入差额拆分」列组（量差、价差、汇率差、口径差）不显示，明细表的预算费率、实际费率、费率差三列不显示；实际本币显示「待 BI」；预算、实际、差额、达成率照常显示（DEC-F10-02）。

### 5.5 偏差说明（AC-F10-11）
- 键：月份 × 店铺站点 / B 端客户（含未归属渠道）。
- 只显示最新一条，修改记录进入审计日志（DEC-F10-05）。
- 财务BP 在弹窗中填写或修改，内容为空时就地提示「请填写说明内容」；保存后行内显示说明、填写人、填写时间。
- 有本页查看权限的角色都能看到对应行的说明（只读弹窗看全文）。

### 5.6 达成条
宽 96px，0–120% 映射到条宽，刻度线 = 100%（当月对当月）。收入类（收入、毛利、库存索赔）：低于 90% 琥珀、低于 70% 红；费用类（退款与各项费用）：超过 100% 红。差额文字：收入类正为绿、负为红；费用类正为红、负为绿。
