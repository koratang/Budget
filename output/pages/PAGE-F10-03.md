## 2. 页面概述

### 2.1 一句话定位
每两个月随 BI 数据看一次：各品类的新品、老品在 SPU 数、销量、品效和收入上比预算差在哪里。

### 2.2 存在理由
1. 预算驱动是「SPU 数 × 单 SPU 销量 × 单价」，偏差必须回到这三个驱动上才能指导上新和备货（REQ-F10-03）。
2. 新品上架延期是常见偏差来源，单看渠道报告看不出来。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 覆盖 | 每两个月 100% 品类有对比（PRD §6.2） |
| 一致 | 合计收入与 PAGE-F10-02 同月平台渠道预算、BI 口径实际一致 |

### 2.4 不做什么
- **不做** SKU 级明细——本期明确不做 SKU 级预算。
- **不做**没有 BI 实际的月份——AC-F10-06 只对已有 BI 实际的月份生成。
- **不做**达成率与达成条——AC-F10-06 只要求预算、实际、差额。

## 5. 界面内容

### 5.1 筛选
- 月份：只列已导入 BI 实际的月份（样例 2027-01 至 2027-04），默认最近一个；旁注下一批 BI 预计导入时间。

### 5.2 主表列（AC-F10-06）

| 分组 | 列 |
| :--- | :--- |
| 维度（冻结） | 品类（框镜、灯镜、镜柜、浴室门）、新品/老品 |
| SPU 数 | 预算、实际、差额 |
| 销量（件） | 预算、实际、差额 |
| 品效（折后 · 人民币元/SPU） | 预算、实际、差额 |
| 收入（元） | 预算、实际、差额 |
| 偏差说明 | 同 PAGE-F10-02：说明首行 + 填写人 · 时间；财务BP 可填写/编辑 |

- 品效（折后，AC-F10-06）：预算品效 = 单 SPU 平均销量 × 平均单价 × (1 − 折扣率)；实际品效 = 实际销售额（本币）÷ SPU 数。单一店铺站点（单一币种）内按本币计算。
- 本表各行、小计、合计都跨店铺与币种，按人民币汇总：品效 = Σ(销量 × 折后单价 × 汇率) ÷ ΣSPU 数 = 人民币收入 ÷ SPU 数（预算用预算汇率，实际用当月平均汇率）；合计行第二列注明「品效按人民币汇总」，表下脚注说明该口径（DEC-F10-04）。
- SPU 数跨店铺站点累加，同一 SPU 在多个店铺上架各计一次（DEC-F10-04）。
- 收入：预算按预算汇率折人民币，实际 = BI 本币销售额 × 当月平均汇率；收入 = SPU 数 × 品效，与 PAGE-F10-02 收入合计一致。
- 对比基准固定为最新调整后目标（无调整时为原始目标），口径信息条注明（DEC-F10-03）。
- 新品/老品按 SKU 对照表首次上架日期判定（PAGE-F02-02）。
- 差额着色：销量、品效、收入多于预算为绿，少于为红；SPU 数差额不着色。

### 5.3 偏差说明（AC-F10-11）
键为 月份 × 品类 × 新品/老品；规则与 PAGE-F10-02 §5.5 相同。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有 BI 实际月份 | 主表 |
| 空 | 本年度未导入任何 BI 数据 | 「2027 年还没有导入 BI 数据」；财务BP 见「去导入 BI 数据」→ PAGE-F09-01 |
| 加载 | 请求中 | 骨架行，导出禁用 |
| 错误 | 请求失败 | 「品类报告加载失败」+「重试」 |
| 无权限 | 没有任何渠道/店铺范围 | 「无权限」+「返回工作台」 |

| 边界 | 处理 |
| :--- | :--- |
| 某行预算 SPU 为 0（未计划上新） | 预算品效显示「—」，差额显示实际值 |
| 某行无实际 | 实际显示 0，差额为负 |
