## 2. 页面概述

### 2.1 一句话定位

登录后的第一屏：告诉每个人「现在轮到我做什么」，并让管理层一眼看到全年目标跑得怎么样。

### 2.2 存在理由

1. 15 个部门、多个角色在编制期和每月复盘中都有待办，散落在填报、审批、预警三处，不聚合容易漏（REQ-F03-02、REQ-F07-01、REQ-F11-01）。
2. CEO 与财务负责人关心的成功指标（净利润达成率双口径、预测准确度）在公司汇总里，工作台提供摘要入口（REQ-F10-05）。
3. 财务BP 每月要确认导入是否完成、核对是否有差异，工作台给出提醒。

### 2.3 不做什么

- 不做可配置的卡片布局或自定义看板：需求未要求。
- 不在工作台直接编辑数据或处理审批：只做入口，操作在对应页面完成。
- 不展示审计日志：本期不做审计日志查看页（蓝图 §9）。

## 3. 用户与场景

| 角色 | 打开工作台时最想知道 |
| :--- | :--- |
| CEO | 有什么等我审批；净利润达成率原始 / 调整后各多少；预测准不准 |
| 财务负责人 | 同上 + 编制任务进度 + 全公司未处理预警 |
| 财务BP | 我的成本比例填报、导入是否到最新期间、BI 与金蝶差异有几处 |
| 运营 / B端业务 / 物流物控 | 我负责的填报单位是否待填、是否被退回；我负责范围的预警 |
| 部门负责人 | 本部门待审批、本部门预警 |
| 部门预算专员 | 本部门待填报、本部门预警 |

## 4. 信息架构

1. 页头：标题「工作台」+ 当前日期、预算年度、最近金蝶导入期间
2. 我的待办（三列卡片）：待填报 / 待审批 / 未处理预警
3. 关键数（仅 CEO、财务负责人）：4 张卡片
4. 导入与核对（仅财务BP）：3 张卡片

原型顶部提供角色切换（CEO/财务负责人、财务BP、运营、部门预算专员）与状态切换，用虚线框标注「原型说明，非产品功能」。

| 待审批 | 数量 + 条目（事项名、类型：编制 / 目标调整 / 规则审批，上一环节、提交时间） | 待当前用户审批的事项（REQ-F07-01） | `PAGE-F07-02.html` | `PAGE-F07-01.html` |
| 未处理预警 | 数量 + 条目（对象 + 规则描述、期间、规则名称与版本） | 当前用户数据范围内、状态为未处理的预警（REQ-F11-01） | `PAGE-F11-01.html`（定位到该预警） | `PAGE-F11-01.html` |

- 待填报的状态取值与编制任务看板一致（AC-F03-03）。

### 5.2 关键数（CEO、财务负责人）

| 卡片 | 内容 | 规则 | 来源 |
| :--- | :--- | :--- | :--- |
| 累计净利润达成率 · 年初原始目标 | 百分比（1 位小数）+ 达成条 + 期间（如 2027-01～04）+ 实际 / 目标金额 | 年初至最近导入月实际净利润合计 ÷ 同期年初原始目标净利润合计；同期目标合计 ≤ 0 显示「—」；卡片注明该口径 | AC-F10-08 |
| 累计净利润达成率 · 调整后目标 | 同上，标注所用调整版本 | 年初至最近导入月实际合计 ÷ 同期最新调整后目标合计；尚无调整版本时等于原始目标并注明「尚无调整版本」；同期目标合计 ≤ 0 显示「—」 | AC-F10-08 |
| 最近季度预测偏差 | 最近一个已发布快照所属季度中、已导入金蝶实际各月的「|快照预测净利润率 − 实际净利润率|」，单位：个百分点，1 位小数 | 大于 1.5 个百分点标红；净利润率 = 净利润 ÷ 人民币收入 | AC-F10-10 |
| 编制任务提交率 | 进行中的编制任务：已提交单位数 ÷ 全部单位数（百分比 + 「x / y 个单位」）；无进行中任务时显示「无进行中的任务」并给出最近一次任务的结果 | 提交率 =（已提交 + 已通过）÷ 全部单位，已退回不计入 | AC-F03-03、DEC-F03-03 |

卡片底部链接：预测偏差 → `PAGE-F10-01.html`；提交率 → `PAGE-F03-01.html`（有进行中任务时直达 `PAGE-F03-02.html`）。

达成条颜色沿用设计系统收入类规则；不利为红、有利为绿，中性为深灰。

### 5.4 原型样例（2027-05-12）

- 财务负责人：待审批 2（第二季度目标调整 · 运营部；规则「品类毛利率比预算低 3 个百分点」v2）；未处理预警 3（TikTok-US-01 新渠道连续 2 个月达成率 < 70%；人力资源部培训费额度使用率超时间进度 10 个百分点；灯镜毛利率比预算低 3 个百分点）。
- 关键数：原始口径 88.0%（¥ 4,965,429.67 / ¥ 5,645,600.00）；调整后 91.5%（¥ 4,965,429.67 / ¥ 5,424,200.00），与 PAGE-F10-01 一致；第一季度快照预测偏差 1 月 0.6、2 月 1.2、3 月 1.9（红）个百分点；无进行中的编制任务。
- 财务BP：待填报 1（第二季度滚动预测 · 成本比例）；金蝶 2027-04、BI 2027-04、差异超 3% 组合 2 个。
- 运营王浩：待填报 1（第二季度滚动预测 · Amazon 平台渠道）；无预警。
- 部门预算专员郑可：无待填报；本部门预警 1。

## 6. 交互流程

- 进入页面：按当前用户的角色与数据范围组装卡片；多角色员工合并显示各角色的待办与关键数（DEC-F00-01）。
- 点击条目或「查看全部」跳转到对应页面；目标页再次按数据范围校验（AC-F01-11）。
- 页面不提供编辑操作。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有数据 | 待办 + 角色关键数 |
| 空 | 无待办；或尚无原始目标 / 未导入实际 | 每张待办卡片显示 0 与一句说明（如「当前没有需要你填报的单位」）；关键数区显示「还没有可计算的关键数」及说明，财务负责人附「发布编制任务」按钮（→ `PAGE-F03-01.html`） |
| 加载 | 数据请求中 | 卡片骨架 |
| 错误 | 请求失败 | 「工作台数据加载失败」+ 说明「网络异常或服务暂时不可用，请重试」+「重试」 |
| 无权限 | 会话中角色被全部撤销（AC-F01-04 后的下一次请求） | 「未开通预算权限，请联系财务负责人」，不返回任何数据，提供「返回登录页」 |

边界：

| 场景 | 处理 |
| :--- | :--- |
| 尚无调整后目标 | 调整后口径等于原始目标，卡片注明「尚无调整版本」 |
| 同期目标净利润合计 ≤ 0 | 该口径达成率显示「—」，不画达成条（AC-F10-08） |
| 最近季度尚未发布快照 | 预测偏差显示上一个已发布快照季度；从未发布过快照时显示「尚无已发布的滚动预测快照」 |
| 某月 BI 未导入 | 差异组合数只统计两方都已导入的月份 |

## 8. 业务规则

- 待办与预警按服务端数据范围过滤（NFR-003）；运营只见负责渠道/店铺、B端业务只见负责客户、部门角色只见本部门（AC-F01-06～08）。
- 无权限的菜单在侧栏隐藏（蓝图 §2）；侧栏为当前用户各角色可见菜单的并集（DEC-F00-02）：

| 菜单 | 可见角色 |
| :--- | :--- |
| 基础数据（渠道与店铺、SKU 对照表、B端客户与部门、科目映射、汇率） | 财务BP（维护）、财务负责人、CEO（只读） |
| 系统设置 · 角色与权限 | 财务负责人（AC-F01-05） |
| 编制任务 | 财务负责人、CEO（只读） |
| 实际数（实际数导入、BI 与金蝶核对） | 财务BP、财务负责人 |
| 规则库 | 财务BP、财务负责人、CEO（只读） |
| 报表与预警 | 所有角色，按数据范围；其中公司汇总只对 CEO、财务负责人、财务BP 开放 |
| 我的填报、部门费用、待我审批、版本管理 | 不在矩阵内，保持原有入口，进入后按角色与数据范围显示 |

  原型角色切换中「CEO / 财务负责人」为两角色合并视图，运营、部门预算专员不显示基础数据、编制任务、实际数、规则库、公司汇总。
- 金额 2 位小数千分位，百分比 1 位小数，偏差单位为「个百分点」。
