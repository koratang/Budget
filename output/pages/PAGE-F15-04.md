## 2. 页面概述

### 2.1 一句话定位
说明业务指标如何传导到财务结果，并从财务缺口反查业务动因与责任部门。

### 2.2 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 一致 | 4 业务一级 → 7 财务一级、12 条主传导路径、31 条明细，与原工作台一致（AC-F15-05） |
| 即时 | 节点达成率、反向归因数字随指标编辑即时更新 |

### 2.3 不做什么
- **不做**传导关系的编辑——关联规则来自引擎常量 `LINKAGE`，可在 PAGE-F15-09 导出。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 财务负责人 林晓、CEO 周明远 |
| 频次 | 经营复盘时 |

**场景 A**：林晓把鼠标移到「净利润 42%」节点，与其相连的营销板块、仓配履约板块路径高亮，其余淡出。
**场景 B**：在明细表搜索「物流物控部」，只留下该部门负责的关联行。

## 4. 信息架构

1. 页头（外壳）：标题 +「示例数据」、描述「业务指标 → 财务指标 传导路径与量化影响」、年度 / 月度、期间
2. 联动关系图谱卡（徽标：4 业务一级 → 7 财务一级、12 条主传导路径、业务健康度 / 业务指标待填报）+ 图例
3. 两栏（1 : 2）：联动层级结构 ｜ 财务偏差反向归因（5 条）
4. 业财关联关系明细表 + 搜索框

## 5. 界面内容

### 5.1 图谱（SVG）

| 元素 | 说明 |
| :--- | :--- |
| 左列节点 | S1 营销板块、S2 产品板块、S3 供应链板块、S4 仓配履约板块：名称、「编码 · n 项二级 · 部门」、右侧达成率或「待填报」 |
| 右列节点 | F1–F7：名称、「编码 · 单位 · 实际 x」、达成率（示例：F1 82%、F2 74%、F3 90%、F4 42%、F5 51%、F6 0%、F7 55%），按 ≥100 / ≥90 / ≥80 / 其余着色 |
| 连线 | 12 条贝塞尔曲线，线宽 ∝ 关联强度；蓝 = 同向，橙 = 反向 |
| 图例 | 同向传导、反向传导、线宽 ∝ 关联强度、节点右侧数字为当前达成率 |

### 5.2 联动层级结构与反向归因
- 层级结构：业务二级 → 业务一级 → 财务一级 → 财务二级，及反查路径文字。
- 反向归因 5 条（引擎 `buildReverse`）：毛利率缺口 3.6pt（损失约 354 万元）、期间费用率超标、经营净现金流缺口 680 万元、净利润达成率仅 42%、应收账款周转天数超目标 8 天；每条附业务动因、责任部门、缺口量化。

### 5.3 明细表列

| 列 | 说明 |
| :--- | :--- |
| 业务指标 | 编码徽标 + 名称 |
| 财务指标 | 编码徽标 + 名称 |
| 方向 | 正向 / 负向 |
| 关联强度 | 条（≥70% 红、≥50% 琥珀、其余灰）+ 百分比 |
| 传导逻辑、责任部门、量化影响 | 文本换行显示 |

搜索匹配业务 / 财务名称与编码、部门、传导逻辑；无结果显示空态。

## 6. 交互流程

```
悬停节点 → 高亮相连边与对侧节点，其余淡出；移出图谱 → 恢复
搜索框输入 → 即时过滤明细表
维度切换 → 节点达成率与反向归因重算
```
