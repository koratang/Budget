## 2. 页面概述

### 2.1 一句话定位

让 B 端业务按客户和月份填写销售预估与费率，B 端收入和毛利进入同一份利润预算。

### 2.2 存在理由

1. B 端客户（Ferguson、Menards、Bauhaus）收入不经平台，需要单独按客户预估（US-F04-02）。
2. B 端毛利口径必须与平台渠道一致，才能汇总到公司净利润（AC-F06-05、AC-F06-07）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 口径一致 | B 端毛利公式与平台渠道完全相同（AC-F06-05） |
| 默认值 | 平台佣金率、库存索赔率初始为 0%（AC-F04-03） |

### 2.4 不做什么

- 不填采购成本占比与物流四项比例（财务BP、物流物控填，本页只读引用）。
- 不按品类拆分 B 端收入——需求维度只有「月 × B 端客户」。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | B端业务：美国业务部孙婷（Ferguson、Menards，USD）、外贸部刘洋（Bauhaus，EUR） |
| 技术熟练度 | 熟练使用 Excel |
| 使用场景 | 编制期按客户年度合同和订单节奏预估每月销售额 |

**主场景**：打开本单位填报 → 按客户逐月填写销售额与费率（或粘贴、上传模板）→ 看到人民币收入与毛利 → 提交审核。
**兜底场景**：被部门负责人退回 → 按原因修改 → 重新提交。

## 4. 信息架构

1. 页头：标题「B端填报 · 美国业务部」、任务与截止日期、负责客户、状态徽章、保存状态
2. 信息条：客户币种、2027 预算汇率、佣金率与索赔率默认 0% 说明
3. 提示区：已退回 / 已提交锁定 / 保存冲突 / 超范围错误
4. 关键数：全年销售额（本币）、全年收入（人民币）、全年毛利、全年毛利率
5. 工具栏：填充全年、下载填报模板、上传填报文件、提交审核
6. 填报表格：冻结「B 端客户」「项目」两列，1–12 月 + 全年
7. 毛利计算引用的比例（折叠，只读）

## 5. 界面内容

### 5.1 元素清单

**每个客户一组（6 输入 + 3 计算）**

| 项目 | 类型 | 格式 | 原型示例（Ferguson · 1 月） | 依据 |
| :--- | :--- | :--- | :--- | :--- |
| 销售额（USD） | 输入 | 2 位小数，列名带币种 | 180,600.00 | AC-F04-03、AC-F06-08 |
| 退款率 | 输入 | 百分数 | 2.0% | AC-F04-03 |
| 推广费用率 | 输入 | 百分数 | 3.0% | AC-F04-03 |
| 其他运营费用率 | 输入 | 百分数 | 1.0% | AC-F04-03 |
| 平台佣金率 | 输入，默认 0% | 百分数 | 0.0% | AC-F04-03 |
| 库存索赔率 | 输入，默认 0% | 百分数 | 0.0% | AC-F04-03 |
| 收入（人民币） | 计算 | 销售额 × 预算汇率 | 1,285,872.00 | AC-F06-05 |
| 毛利（人民币） | 计算 | 同 AC-F06-03/04 公式 | 385,761.60 | AC-F06-05 |
| 毛利率 | 计算 | 毛利 ÷ 人民币收入；收入为 0 显示「—」 | 30.0% | AC-F06-04 |

**合计**：销售额（USD）、收入（人民币）、毛利、毛利率，按月与全年。不同币种的客户在同一单位时，本币合计按币种分行（原型两客户均为 USD）。

**毛利计算引用的比例（只读）**：每个客户的采购成本占比、头程、尾程、仓储、关税率。

### 5.2 辅助信息

- 「平台佣金率、库存索赔率默认 0.0%，有实际约定时再改」
- 表格说明同 PAGE-F04-02（失焦保存、Enter、Esc、粘贴、百分数录入）。

### 调整模式（目标调整，DEC-F08-04）

财务负责人在 PAGE-F08-01 发起季度目标调整后，填报人从「我的填报」进入本页，以「调整模式」打开（与 PAGE-F04-02 相同）：
- 页头副标题改为「2027 年第二季度目标调整 · 调整模式 · 截止 2027-05-20」，显示调整提示条「1–4 月已导入金蝶实际，不可修改；只能调整 5–12 月。提交时须填写调整原因，经部门负责人、财务负责人审核后，由 CEO 对整次调整一次性终审。」
- 已导入金蝶实际的月份表头标「（实际）」，输入单元格灰显不可编辑（AC-F08-02）；「填充全年」只写入可编辑月份。
- 「调整原因 *」必填，为空提交时提示「请填写调整原因」（AC-F08-03）；提交按钮为「提交调整」，确认弹窗说明部门负责人 → 财务负责人逐个审核、CEO 整次终审（AC-F08-04）。

## 6. 交互流程

- 单元格编辑、粘贴、填充全年、保存冲突、模板下载上传、提交与锁定：全部沿用 PAGE-F04-02 §6 的规则。
- 本页提交前检查：无未保存的超范围单元格；涉及币种有 2027 预算汇率（AC-F02-07）。本页无新渠道理由检查。
- 提交确认文案：「提交后状态变为「已提交」，并通知美国业务部负责人审核。被退回之前不能再修改。」
- 上传错误示例：第 5 行 · 推广费用率 ·「120%」超出取值范围，允许范围：0% 到 100%；第 9 行 · 销售额（USD）·「-15,000」小于 0；第 13 行 · B 端客户 ·「Bauhaus」不在你的数据范围内。

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 销售额 | 失焦 / 粘贴 / 上传 | 大于等于 0，最多 2 位小数（DEC-F04-07） | 「允许范围：大于等于 0，最多 2 位小数」 |
| 五个比率 | 同上 | 0% 到 100% | 「允许范围：0% 到 100%」 |
| 预算汇率 | 提交 | 涉及币种均有 2027 预算汇率 | 「2027 年度缺少以下币种的预算汇率：USD…」 |

- 人民币收入 = 销售额（本币）× 预算汇率；毛利 = 人民币收入 − 退款 − 采购成本 − 平台佣金 − 推广费用 − 头程 − 尾程 − 关税 − 仓储 + 库存索赔 − 其他运营费用（AC-F06-05）。
