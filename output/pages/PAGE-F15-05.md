## 2. 页面概述

### 2.1 一句话定位
按原工作台九个分析模型，从渠道、流量、用户、订单、品类、物流、仓储、管理费用拆解经营结果。

### 2.2 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 口径一致 | 渠道贡献毛利合计 = F4 净利润（示例 553.9 万元）、贡献毛利率合计 = F5（5.63%）（AC-F15-06） |
| 数据来源透明 | 依赖推算模型的 8 个子模块始终标「示例数据」并说明原因（AC-F15-03） |
| 回落 | 业务指标已填报时用填报值（如 S1.2 转化率、S1.3 客单价），未填报回落结构基准 |

### 2.3 不做什么
- **不做**分析结果的编辑或导出——数据来源于 PAGE-F15-02 / 03 / 09。
- **不做**服务商、海外仓的真实数据接入——平台暂无数据源，按结构基准推算。

## 3. 用户与场景

**场景 A**：林晓打开数据分析，默认「渠道效益分析」，矩阵显示 Wayfair 毛利额 −87 万元、毛利率 −4.4%，KPI「毛利最低渠道 Wayfair」红色左边框。
**场景 B**：周明远点「流量分析」，URL 变为 `/bizfin/analysis/anaTraffic`，标题变为「数据分析 · 流量分析」，说明条改为推算数据说明。

## 4. 信息架构

1. 页头（外壳）：标题「数据分析 · 子模块名」+「示例数据」、子模块描述、年度 / 月度、期间
2. 示例数据说明条（渠道效益：示例部分说明；其余 8 个：推算数据说明）
3. 页签条（9 个）
4. 当前子模块：口径说明卡（多数子模块）→ KPI 行 → 明细表 → 图表（每图带结论说明）

## 6. 交互流程

```
点页签 → router.replace('/bizfin/analysis/<id>') → 标题、描述、示例数据说明切换 → 渲染对应子模块
年度 / 月度切换 → 当前子模块全部数值与图表按期间重算
```

## 7. 状态与边界

| 状态 | 页面表现 |
| :--- | :--- |
| 加载 / 错误 / 无权限 | 同外壳：骨架；「业财分析数据加载失败」+「重试」；403 无权限 +「返回工作台」 |
| 推算子模块 | 始终显示「示例数据」，说明「平台暂无流量、新老客、订单、服务商单价、库存等数据源」，导入正式指标后也不消失 |
| 业务指标未填报 | 相关 KPI 脚注显示「结构基准（S1.2 待填报）」等 |
