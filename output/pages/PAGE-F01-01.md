## 2. 页面概述

### 2.1 一句话定位

让员工用钉钉身份进入预算系统，没有预算角色或账号已停用的人被挡在门外并知道原因。

### 2.2 存在理由

1. 系统含全公司收入、利润与部门费用，必须先识别身份再按角色返回数据（REQ-F01-01、REQ-F01-03）。
2. 用户已选择钉钉登录且不提供账号密码（requirements「Capability prerequisites」、PRD §10.3 OQ-11），员工离职后账号随钉钉自动失效。
3. 钉钉企业内部应用 2026-11-30 才就绪，本机验收阶段需要模拟各角色登录（DEC-002）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 准入正确 | 已分配角色的员工 100% 进入工作台并看到姓名与角色名（AC-F01-01） |
| 拒绝正确 | 无角色员工、停用账号 100% 被拒（AC-F01-02、AC-F01-03） |
| 生产安全 | 生产配置下页面源码与界面均不出现开发模式身份切换（DEC-002） |

### 2.4 不做什么

- **不做**账号密码、短信验证码、找回密码、注册：上游已确认唯一认证方式为钉钉（OQ-11）。
- **不做**页面内选择角色：角色由财务负责人在 `PAGE-F01-02.html` 分配，登录后由系统识别。
- **不做**钉钉不可用时的备用登录：PRD §5.3 已确认不提供。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | CEO、财务负责人、财务BP、运营、B端业务、物流物控、部门负责人、部门预算专员 |
| 使用设备 | 办公电脑浏览器、电脑版钉钉内置浏览器；手机钉钉用于扫码 |
| 技术熟练度 | 日常使用钉钉，熟悉扫码登录 |

### 3.2 核心使用场景

**场景 A：浏览器扫码登录（主场景）**：员工在电脑浏览器打开系统 → 看到钉钉二维码 → 用手机钉钉扫码并确认 → 进入工作台。

**场景 B：钉钉工作台免登**：员工在电脑版钉钉工作台点开「预算管理平台」→ 系统自动取得钉钉身份，不显示二维码 → 直接进入工作台。

**场景 C：从钉钉工作通知进入**：编制任务、审批、预警通知中带系统链接（AC-F03-01、AC-F07-01、AC-F11-04）→ 未登录时先经过本页 → 登录后回到通知原链接（DEC-F01-03）。

**场景 D：被拒绝**：无角色或账号停用的员工完成扫码后看到拒绝原因，不进入系统。

**场景 E：本机验收（仅开发配置）**：验收人员在「开发模式身份切换」中选择一个样例身份，以该身份进入系统。

### 3.3 用户核心诉求

1. **快**：扫一次码或在钉钉里点一下就进入。
2. **明白**：被拒时知道原因和该找谁。

## 6. 交互流程

### 6.1 页面加载

```
打开 /login
  ├─ 已有有效会话 → 直接跳转 PAGE-F00-01 · 工作台
  ├─ 在钉钉内置浏览器中 → 自动免登（显示「正在验证钉钉身份…」），不显示二维码
  └─ 普通浏览器 → 显示钉钉二维码
```

### 6.2 核心流程

```
钉钉扫码确认 / 钉钉内免登
  │
  ▼
系统取得钉钉身份 → 查询通讯录状态与系统角色
  ├─ 账号已停用或不在通讯录 → 显示「账号停用」提示，不建立会话（AC-F01-03）
  ├─ 无任何角色 → 显示「未开通预算权限，请联系财务负责人」，不建立会话（AC-F01-02）
  └─ 有至少一个角色 → 建立会话 → 进入 PAGE-F00-01 · 工作台，顶栏显示姓名与角色名（AC-F01-01）；
       从钉钉通知链接进入的，改为回到原链接（DEC-F01-03）
```

- 拒绝提示中的「换个账号扫码」返回二维码状态。
- 已登录员工的钉钉账号被停用后，其下一次页面请求时会话失效，回到本页并显示「登录已失效，请重新登录」（AC-F01-03）。

### 6.3 开发模式身份切换（DEC-002）

选择身份 → 点「以此身份进入」→ 按该身份已分配的角色与数据范围建立会话 → 进入工作台；选择「未分配角色」身份时走与钉钉相同的拒绝分支。生产配置下该区域不渲染、对应入口在服务端关闭。

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常（初始） | 未登录，普通浏览器 | 二维码 + 免登说明 |
| 加载 | 扫码确认后 / 钉钉内免登进行中 | 扫码区替换为「正在验证钉钉身份…」 |
| 错误 | 钉钉二维码或身份接口不可用 | 「钉钉登录暂不可用，请稍后重试」+ 重新加载 |
| 无权限 | 验证成功但无角色 | 「未开通预算权限，请联系财务负责人」（AC-F01-02） |
| 无权限（停用） | 账号停用或移出通讯录 | 账号停用提示（AC-F01-03） |
| 会话失效 | 从失效会话重定向 | 二维码上方显示「登录已失效，请重新登录」 |
| 空 | 不适用：本页不展示业务数据 | — |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 钉钉服务不可用 | 所有人无法登录，只提示重试，不提供备用登录（PRD §5.3） |
| 角色被财务负责人全部撤销 | 下一次请求按无角色处理，回到本页显示 AC-F01-02 文案（AC-F01-04 + AC-F01-02） |
| 会话 8 小时无操作 | 失效并回到本页（蓝图 §9） |
| 生产配置误开开发模式 | 生产配置强制关闭，不受页面参数影响（DEC-002） |

## 8. 业务规则与校验

- 认证方式只有钉钉扫码与钉钉工作台免登（REQ-F01-01）。
- 准入条件：钉钉账号在企业通讯录中有效 且 系统中至少有一个角色。
- 会话时效：8 小时无操作失效（蓝图 §9）。
- 浏览器：Chrome / Edge 当前及前一个大版本、钉钉内置浏览器，桌面宽度 ≥ 1280 像素无错位（NFR-006）。

## 9. 页面流转

```
钉钉工作台 / 浏览器 / 通知链接 / 会话失效
          │
          ▼
     登录页（本页）──拒绝──→ 停留本页显示原因
          │
       验证通过
          ▼
  PAGE-F00-01 · 工作台（PAGE-F00-01.html）；来自通知链接时回到原链接
```

应用内顶栏「退出」回到本页。
