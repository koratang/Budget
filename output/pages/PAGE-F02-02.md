## 2. 页面概述

### 2.1 一句话定位

维护「SKU → SPU → 品类 + 首次上架日期」对照，并让财务BP 按任一月份核对每个 SPU 被判为新品还是老品。

### 2.2 存在理由

1. BI 数据是 SKU 级，必须经对照表归集到「品类 × 新老品」才能与预算比较（PRD §3.3.9）。
2. 新老品判定口径直接影响品效预算与偏差分析，需要可查看、可核对（AC-F02-04）。

### 2.3 不做什么

- 不做逐行在线编辑：需求为整表上传（PRD §3.3.2）。
- 不做手工指定新老品：一律按 AC-F02-04 规则计算。

## 3. 用户与场景

- **场景 A：月度更新**：新品上架后，财务BP 从 ERP 导出对照表 → 上传 → 校验通过 → 确认写入。
- **场景 B：校验失败**：文件中有行缺品类或日期 → 系统拒绝整份文件并列出行号与缺失字段 → 财务BP 在 Excel 中补齐重传（AC-F02-03）。
- **场景 C：核对判定**：运营质疑某款灯镜在 5 月被算作老品 → 财务BP 选择判定月份 2027-05，查看该 SPU 的首次上架日期与新品期截止日。

## 4. 信息架构

1. 页头：标题 +「上传对照表」
2. 当前对照表概况：SKU 数、SPU 数、品类数；最近上传时间、上传人、文件名
3. 判定月份选择 + 规则说明（显示所选月最后一天）
4. 筛选：搜索 SKU / SPU、品类、新品 / 老品；右侧统计所选月新品 SPU 数
5. 对照表列表 + 分页（每页 50 条）
6. 上传弹窗：选择文件 → 校验中 → 失败清单 / 通过确认

## 5. 界面内容

### 5.1 列表字段

| 列 | 内容 |
| :--- | :--- |
| SKU | 等宽显示，如 FM-3022-BK |
| SPU 编码 | 如 SPU-FM-3022 |
| 品类 | 框镜 / 灯镜 / 镜柜 / 浴室门 |
| SKU 首次上架日期 | YYYY-MM-DD，右对齐等宽 |
| SPU 首次上架日期 | 该 SPU 下各 SKU 首次上架日期的最早值（DEC-F02-05） |
| 新品期截止 | SPU 首次上架日期 + 12 个月 |
| {所选月} 判定 | 新品 / 老品徽章 |

### 5.2 上传弹窗

- 说明：「整表上传 Excel（.xlsx），按 SKU 新增或更新，文件中未出现的 SKU 保留不删除。必须包含以下四列；任一行缺字段、日期格式错误、SKU 重复、品类不在清单（框镜、灯镜、镜柜、浴室门）或同一 SPU 下 SKU 品类不一致时，整份文件不写入：SKU、SPU 编码、品类、首次上架日期（YYYY-MM-DD）」。
- 校验中：「正在校验 {文件名} …」。
- 校验失败：标题「校验未通过，整份文件未写入（N 行有问题）」+「请在 Excel 中修正后重新上传。当前对照表保持不变。」+ 问题清单（行号、SKU、问题：缺少某字段 / 日期格式错误 / SKU 重复 / 品类不在清单 / 同一 SPU 品类不一致）；按钮「重新选择文件」。
- 校验通过：「校验通过：共 N 行（新增 a 个 SKU，更新 b 个 SKU）」+「确认写入后，按 SKU 新增或更新对照表；文件中未出现的 SKU 保留不删除。各月新老品判定按新对照表重新计算。」；按钮「确认写入」→ 轻提示「已写入 SKU 对照表，共 N 行」。

原型弹窗内的「模拟上传」按钮以虚线框标注「原型说明，非产品功能」。

## 6. 交互流程

```
点「上传对照表」→ 选择 .xlsx
  → 校验每一行四个字段
     ├─ 任一行缺字段 → 整份拒绝，列出每个问题行的行号和缺失字段（AC-F02-03）
     ├─ 日期格式错误 / SKU 重复 / 品类不在清单 / 同一 SPU 品类不一致 → 同样整份拒绝并列出（DEC-F02-05）
     └─ 全部通过 → 显示行数与新增 / 更新数 → 「确认写入」→ 按 SKU 增改 → 列表与判定刷新
修改「判定月份」→ 判定列与新品统计即时按 AC-F02-04 重算
```

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 四列必填 | 上传后 | 每行 SKU、SPU 编码、品类、首次上架日期均不为空 | 行号 + 缺失字段，整份不写入（AC-F02-03） |
| 日期格式 | 上传后 | 首次上架日期为 YYYY-MM-DD 有效日期 | 行号 +「日期格式错误」，整份不写入（DEC-F02-05） |
| SKU 唯一 | 上传后 | 同一文件内 SKU 不重复 | 行号 +「SKU 重复：与第 n 行相同」，整份不写入（DEC-F02-05） |
| 品类清单 | 上传后 | 品类为框镜、灯镜、镜柜、浴室门之一 | 行号 +「品类不在清单」，整份不写入（DEC-F02-05） |
| SPU 品类唯一 | 上传后 | 同一 SPU 下各 SKU 的品类相同 | 行号 +「同一 SPU 品类不一致：SPU-xxx 在第 n 行为「A」，本行为「B」」，整份不写入（DEC-F02-05） |
| 文件类型 | 选择文件 | .xlsx | 「请上传 .xlsx 文件」 |

- 新老品判定（AC-F02-04）：某月最后一天早于「SPU 首次上架日期 + 12 个月」→ 新品，否则老品；SPU 首次上架日期取其下 SKU 最早日期。
- 写入方式：按 SKU 新增或更新，不删除旧 SKU（DEC-F02-05）。
- 校验时间要求参照导入类 NFR-002（≤ 50,000 行 60 秒内出结果）。
