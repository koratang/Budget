## 2. 页面概述

### 2.1 一句话定位

让物流物控只看、只填四项物流比例，不接触收入和利润。

### 2.2 存在理由

1. 物流费按收入比例估算，物流物控最了解头程、尾程、仓储、关税成本（US-F04-03）。
2. 物流物控不应看到收入与利润（AC-F01-09）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 字段隔离 | 页面、模板、接口中 0 处出现收入、销量、利润或其他费率 |
| 效率 | 全年相同比例一次「填充全年」完成 |

### 2.4 不做什么

- **不显示**收入、销量、毛利、毛利率及其他费率（AC-F01-09）——包括关键数卡片、合计行和提示文案。
- 不按店铺或新老品拆分——需求维度为「渠道 × 站点 × 品类」与「B 端客户」。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 物流物控部（填报人蒋帆，部门负责人何建国审核） |
| 场景 | 编制期依据货代合同、海外仓报价、关税税率估算各渠道站点品类比例 |

**主场景**：选择标签与渠道 → 逐格或整块粘贴四项比例 → 「填充全年」→ 提交。

## 4. 信息架构

1. 页头：标题、任务与截止日期、状态徽章
2. 提示区：已退回 / 已提交锁定 / 保存冲突 / 超范围错误
3. 标签页：平台渠道（渠道 × 站点 × 品类）｜B 端客户
4. 工具栏：填充全年、下载填报模板、上传填报文件、渠道筛选（平台标签）、保存状态、提交审核
5. 填报表格：只有四个比例行

## 5. 界面内容

### 5.1 元素清单

**平台渠道标签（AC-F04-05）**
- 冻结列：渠道、站点、品类、比例；每个「渠道 × 站点 × 品类」4 行：头程费率、尾程费率、仓储费率、关税率；横向 1–12 月。
- 示例：Amazon · 美国 · 框镜：头程 5.0%、尾程 8.0%、仓储 2.0%、关税 6.0%；Amazon · 英国 · 框镜：6.0%、9.5%、2.5%、3.5%。
- 说明：「只填写头程费率、尾程费率、仓储费率、关税率四项；各项按人民币收入的百分比计算。」

**B 端客户标签（AC-F04-05）**
- 冻结列：B 端客户、负责部门、比例；每客户 4 行。示例：Ferguson 5.0% / 2.0% / 1.0% / 6.0%；Bauhaus 6.0% / 2.5% / 1.0% / 3.5%。

**无合计列、无关键数卡片**（比率不做求和）。

### 5.2 辅助信息

表格下方右侧：「本页不显示收入、销量与利润」。

### 调整模式（目标调整，DEC-F08-04）

财务负责人在 PAGE-F08-01 发起季度目标调整后，填报人从「我的填报」进入本页，以「调整模式」打开（与 PAGE-F04-02 相同）：
- 页头副标题改为「2027 年第二季度目标调整 · 调整模式 · 截止 2027-05-20」，显示调整提示条「1–4 月已导入金蝶实际，不可修改；只能调整 5–12 月。提交时须填写调整原因，经部门负责人、财务负责人审核后，由 CEO 对整次调整一次性终审。」
- 已导入金蝶实际的月份表头标「（实际）」，输入单元格灰显不可编辑（AC-F08-02）；「填充全年」只写入可编辑月份。
- 「调整原因 *」必填，为空提交时提示「请填写调整原因」（AC-F08-03）；提交按钮为「提交调整」，确认弹窗说明部门负责人 → 财务负责人逐个审核、CEO 整次终审（AC-F08-04）。

## 6. 交互流程

- 编辑、粘贴、填充全年（AC-F04-06）、保存冲突、模板、提交锁定：沿用 PAGE-F04-02 §6。
- 模板只含四个比例列及其维度（AC-F04-07 + AC-F01-09）。上传错误示例：第 23 行 · 关税率 ·「-2%」超出取值范围；第 57 行 · 尾程费率 ·「9..5」不是数字；第 140 行 · 收入 ·「收入」不是本人负责的输入项，请删除该列后重新上传。
- 提交：通知物流物控部负责人何建国审核。
