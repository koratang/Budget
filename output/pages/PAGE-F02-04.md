## 2. 页面概述

### 2.1 一句话定位

维护预算科目清单，并把金蝶的会计科目翻译成预算科目，让金蝶实际数能和预算逐科目对比；导入中冒出的新科目在这里一眼看到并补上映射。

### 2.2 存在理由

1. 金蝶科目与预算科目口径不同，导入时必须按映射归集（AC-F02-05）。
2. 金蝶中新增科目会导致导入整份失败（AC-F09-01），需要集中暴露并快速补映射。
3. 部门费用按「预算科目 × 月」填报，预算科目会增减改名，需要财务BP 自行维护清单（AC-F02-12）。

### 2.3 不做什么

- 不删除预算科目或映射：预算科目只可停用（AC-F02-12），映射只可修改（DEC-F02-07）。
- 不重算已导入的历史实际：AC-F02-05 只约束之后的导入（DEC-F02-07）。

## 3. 用户与场景

- **场景 A：初始化**：编制前，财务BP 把金蝶科目表中的收入、成本、费用科目逐个映射到预算科目。
- **场景 B：导入失败补映射**：金蝶 4 月更正文件中出现新科目「6601.35 销售费用-直播服务费」→ 导入整份失败 → 财务BP 在本页「未映射科目」中选择预算科目「推广费用」并保存 → 回到实际数导入重新上传。
- **场景 C：口径调整**：财务BP 修改某科目的归集预算科目，从下一次导入起生效。
- **场景 D：维护预算科目**：公司 2027 年起不再单列「招聘费」→ 财务BP 在「预算科目」标签页停用该科目 → 新的部门费用填报和映射下拉不再出现，2026 年的预算与实际保留；新增「咨询服务费」后部门费用填报中可选（AC-F02-12）。

4. 筛选：搜索编码 / 名称、预算科目；右侧说明「保存后从下一次金蝶导入起，按新映射归集到预算科目」

8. 预算科目列表
9. 新增 / 改名弹窗、停用确认弹窗

## 5. 界面内容

### 5.1 未映射科目区

| 列 | 内容 |
| :--- | :--- |
| 金蝶科目编码 | 如 6601.35 |
| 金蝶科目名称 | 如 销售费用-直播服务费 |
| 出现行数 | 该科目在导入文件中出现的行数 |
| 预算科目 | 下拉（初始「请选择预算科目」） |
| 操作 | 保存映射；未选时提示「请选择预算科目」 |

全部映射后该区域消失。

### 5.2 映射列表

| 列 | 内容 |
| :--- | :--- |
| 金蝶科目编码 | 等宽 |
| 金蝶科目名称 | — |
| 预算科目 | 行内「修改」后变为下拉（只列启用科目）+ 保存 / 取消；所映射科目已停用时标「已停用」 |
| 最近修改 | 日期 + 修改人 |
| 操作 | 修改（无删除，DEC-F02-07；CEO、财务负责人显示「只读」） |

### 5.3 新增映射弹窗

| 字段 | 必填 | 规则 |
| :--- | :--- | :--- |
| 金蝶科目编码 | 是 | 已有映射的编码不能重复新增：「该金蝶科目编码已有映射，请在列表中修改」 |
| 金蝶科目名称 | 否 | — |
| 预算科目 | 是 | 下拉；「请选择预算科目」；说明「保存后从下一次金蝶导入起，该科目金额归集到所选预算科目」 |

原型预算科目样例：收入、退款、采购成本、平台佣金、推广费用、头程、尾程、仓储、关税、库存索赔、其他运营费用、工资薪酬、社保公积金、办公费、差旅费、培训费、福利费、招聘费（已停用）、软件与信息服务费、房租物业费。所有预算科目下拉只列启用科目（AC-F02-12）。

| 最近修改 | 日期 + 修改人 |
| 操作 | 改名；启用科目另有「停用」；CEO、财务负责人显示「只读」 |

### 5.5 新增 / 改名弹窗与停用确认

| 字段 | 必填 | 规则 |
| :--- | :--- | :--- |
| 预算科目名称 | 是 | 「请填写预算科目名称」；与已有科目重名时「预算科目名称已存在」（DEC-F02-08）；说明「保存后，部门费用填报与科目映射的预算科目选项按新清单显示」 |

- 改名：已有预算、实际与映射随之显示新名称（同一科目，数据不迁移）。
- 停用确认：标题「停用预算科目「{名称}」？」；正文「停用后，该科目不再出现在新的部门费用填报和科目映射选项中；已有预算与实际数据保留，已映射到该科目的 n 个金蝶科目映射保留。」；按钮「取消」「确认停用」。

## 6. 交互流程

```
未映射区：选择预算科目 →「保存映射」→ 该科目移入列表 → 轻提示「{编码} 已映射到「{预算科目}」，下一次金蝶导入起生效」
列表：「修改」→ 下拉 → 保存 → 轻提示；取消恢复原值
「新增映射」→ 弹窗 → 校验 → 保存（若该编码在未映射区，同时移出）
预算科目标签：「新增预算科目」→ 弹窗 → 校验必填与重名 → 保存 → 轻提示「已新增预算科目「X」，部门费用填报与科目映射中可选用」
              「改名」→ 弹窗 → 保存 → 轻提示「「A」已改名为「B」，已有预算、实际与映射随之显示新名称」
              「停用」→ 确认弹窗 →「确认停用」→ 状态变为已停用，从各预算科目下拉移除 → 轻提示「已停用「X」」
```

## 8. 业务规则与校验

- 一个金蝶科目编码只映射到一个预算科目；多个金蝶科目可映射到同一预算科目。
- 映射保存后，之后每次金蝶导入将该科目金额归集到所选预算科目（AC-F02-05）。
- 映射不可删除，只可修改；修改只影响之后的导入，已导入月份不重算（DEC-F02-07）。
- 预算科目名称唯一（DEC-F02-08）；停用的科目不出现在新的部门费用填报与映射下拉中，已有预算、实际与映射保留（AC-F02-12）；预算科目不可删除。
- 未映射科目来自金蝶导入校验：导入文件中存在未映射科目时整份不写入（AC-F09-01），这些科目列在本页未映射区。
