## 2. 页面概述

### 2.1 一句话定位

财务负责人一次下发年度编制任务，系统自动用钉钉通知所有填报人。

### 2.2 存在理由

1. 15 个部门和各渠道、B 端、成本比例填报人需要同一时间收到任务和截止日（US-F03-01）。
2. 同一年度并行两个任务会造成数据口径冲突（AC-F03-02）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 通知覆盖 | 发布后每个参与单位的填报人都收到含年度、截止日期、系统链接的钉钉通知（AC-F03-01） |
| 唯一性 | 同年度未完成 CEO 审批的任务最多 1 个（AC-F03-02） |

### 2.4 不做什么

- 不在本页看单位进度——进入 PAGE-F03-02。
- 不做任务编辑、撤销、删除——需求未定义。
- 不发起季度调整或滚动预测——属于 PAGE-F08-01。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 财务负责人（林晓） |
| 频次 | 每年 1 次（2026-12-01 发布 2027 年度任务） |

**主场景**：点「发布编制任务」→ 选预算年度、截止日期 → 勾选参与单位（默认全选，可按类型全选/取消）→ 预览通知 → 「发布并通知」。
**兜底场景**：同年度已有未完成任务 → 阻止并提示已有任务名称。

## 4. 信息架构

1. 页头：标题「编制任务」、说明、「发布编制任务」
2. 任务列表
3. 发布弹窗：预算年度、截止日期、参与填报单位（按类型分组）、钉钉通知预览、错误提示

**发布弹窗**

- 截止日期*：日期选择。
- 参与填报单位*：按类型分组的复选框——平台渠道（9：各店铺）、B端（2）、成本比例（1）、物流比例（1）、部门费用（15），每项显示填报人；分组标题可全选；顶部显示「已选 28 个单位，涉及 n 位填报人」。
- 钉钉工作通知预览（不含金额，NFR-005）：「【预算管理平台】2027 年度预算编制已发布，截止日期 2026-12-20，请在截止前完成填报：<系统链接>」（AC-F03-01）。
- 按钮：取消 /「发布并通知」。

### 5.2 辅助信息

页头说明：「发布年度预算编制任务，系统通过钉钉通知每个参与单位的填报人。同一预算年度只能有一个未完成 CEO 审批的任务。」

## 6. 交互流程

```
点击「发布并通知」
  ├─ 年度为空 →「请选择预算年度」
  ├─ 截止日期为空 →「请选择截止日期」；不晚于今天 →「截止日期须晚于今天（2026-12-22）」（DEC-F03-01）
  ├─ 未选单位 →「请至少选择 1 个参与填报单位」
  ├─ 该年度已有未完成 CEO 审批的任务 →「2027 年度已有未完成 CEO 审批的编制任务「2027 年度预算编制」，不能再发布同年度任务。」（AC-F03-02）
  └─ 通过 → 创建任务「{年度} 年度预算编制」（DEC-F03-01）→ 向每个参与单位填报人发送钉钉工作通知 → 列表顶部新增一行 → 轻提示「已发布「2028 年度预算编制」，已向 18 位填报人发送钉钉工作通知」
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 进入页面 | 骨架行「正在加载编制任务…」 |
| 空 | 尚无任何任务 | 「还没有编制任务」「发布后，系统会通过钉钉通知每个参与单位的填报人，你可以在这里跟踪填报进度。」+「发布编制任务」 |
| 错误 | 网络或服务异常 | 「编制任务加载失败」+「重试」 |
| 只读 | CEO 访问 | 列表可查看，不显示「发布编制任务」（DEC-F00-02） |
| 无权限 | 非财务负责人 / CEO 访问 | 「无权限」「编制任务只对财务负责人开放。」+「返回工作台」 |
| 发布中 | 点击发布后 | 按钮不可重复点击 |

| 边界场景 | 处理策略 |
| :--- | :--- |
| 钉钉通知发送失败 | 任务照常创建；通知按 AC-F11-05 异步重试（预警模块统一规则） |
| 同一人负责多个单位 | 每人只计一次填报人 |

## 8. 业务规则与校验

| 字段 | 说明 |
| :--- | :--- |
| 预算年度 | 编制对象年度 |
| 截止日期 | 逾期提醒的依据（AC-F03-04，见 PAGE-F03-02） |
| 参与填报单位 | 按 AC-F03-05 生成：平台渠道每个启用店铺 1 个（运营）、B 端每个负责部门 1 个（美国业务部、外贸部）、成本比例 1 个（财务BP）、物流比例 1 个（物流物控）、每个参与部门的部门费用 1 个；每个单位独立提交、审核和退回 |

## 11. 验收标准

| 编号 | 验收点 | 通过标准 |
| :--- | :--- | :--- |
| F-01 | 发布即通知（AC-F03-01） | 发布后每个参与单位的填报人收到钉钉通知，内容含预算年度、截止日期和系统链接，不含金额 |
| F-02 | 同年度唯一（AC-F03-02） | 2027 年度任务未完成 CEO 审批时再发布 2027 年度被阻止，提示含已有任务名称 |
| F-03 | 必填校验 | 年度、截止日期、参与单位缺任一项不发布 |
| F-04 | 权限 | 财务负责人、CEO（只读）以外的角色看不到菜单，直接访问显示「无权限」 |
| F-05 | 填报单位划分（AC-F03-05） | 2027 年度任务生成 28 个单位：9 个启用店铺、2 个 B 端负责部门、成本比例 1、物流比例 1、15 个部门费用；各自独立提交、审核、退回 |
| F-06 | 已完成后再发布 | 同年度任务已完成 CEO 审批后可以发布同年度新任务（下一次编制） |
