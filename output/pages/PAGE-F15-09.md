## 2. 页面概述

### 2.1 一句话定位
把正式指标数据批量写进业财分析，并负责导出备份和回到示例数据。

### 2.2 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 导入可核对 | 提示写入条数与未识别行（AC-F15-08） |
| 示例标记 | 导入后「财务与业务指标」「业务指标维度填报」在保存记录中改为「正式数据」；标题「示例数据」标记在五个部分全部为正式数据后才消失（实现按 anyDemo 判断） |
| 可恢复 | 恢复示例数据需二次确认、仅财务负责人、写审计 `bizfin.reset` |

### 2.3 不做什么
- **不做**原工具的登录、用户与权限面板——由平台角色承担（DEC-030）。
- **不做**Excel 直读——提示另存为「CSV UTF-8」。

## 3. 用户与场景

**场景 A**：陈思雨粘贴两列表格（编码、实际值：F1.1 5,200；F9.9 100），点「导入粘贴内容」，提示写入 1 条、未识别 1 条（F9.9）；保存记录中两行变为「正式数据」、最后保存人陈思雨。
**场景 B**：林晓点「恢复示例数据」，弹窗说明会清空服务器上全部业财数据、所有同事受影响，点「确认恢复」后各页重新显示示例数据。
**场景 C**：周明远打开本页，顶部灰条「当前账号对「业财数据管理」仅查看…」，只看到模板下载与导出按钮。

## 4. 信息架构

1. 页头（外壳，无维度切换）：标题 +「示例数据」、描述「表格导入 / 手动填写 / 导出 / 指标字典」

## 5. 界面内容

### 5.1 表格导入卡
拖拽 / 点击选择区（.csv / .txt）、粘贴文本框（占位示例含年度、维度、月度三种格式）；按钮：导入粘贴内容、清空（编辑者）、下载导入模板、下载月度导入模板、下载维度导入模板（所有人）；三段识别规则说明（编码 / 名称匹配与可识别表头；「维度」列写入维度矩阵；「月份」列按当月写入并反算年度）。

### 5.2 导出与数据维护卡

| 区块 | 内容 |
| :--- | :--- |
| 年度口径导出 | 导出全部指标（CSV，主按钮）、财务指标、业务指标、业财关联关系、维度填报明细 |
| 月度口径导出 | 月度明细（全部 / 财务 / 业务）、政策影响清单、重点工作台账；「恢复示例数据」（危险样式，仅财务负责人） |
| 统计 | 财务指标 47（一级 7 / 二级 40）、业务指标 35（一级 4 / 二级 31）、维度填报 0 / 76、关联关系 31、政策事件 4、重点工作 15、部门 12、渠道 5、产品线 6、市场 5、数据存储「平台服务器」 |

CSV 表头与原工作台一致（`IND_HEADER`、`MONTH_HEADER`、`DIM_HEADER`）。

### 5.3 表格

| 表 | 列 |
| :--- | :--- |
| 保存记录 | 数据部分（财务与业务指标、业务指标维度填报、政策环境事件、经营建议、重点工作）、数据来源（示例数据琥珀 / 正式数据绿）、最后保存人、最后保存时间 |
| 指标字典 | 编码、类型（财务 / 业务）、层级、指标名称、单位、方向、计算口径 / 说明、责任部门（82 行） |

### 5.4 维度管理与校验
分段按钮「年度维度 / 月度维度」、01–09 月按钮、已被手工覆盖指标数 +「清空 2026年 09月 的手工覆盖」（编辑者）；4 条口径说明；数据校验结果 10 项（同驾驶舱）。

## 6. 交互流程

```
导入（粘贴 / 文件）→ 引擎 importTable → 成功：commit(['indicators','biz_dim'], 去示例标记) → 轻提示 importMessage（写入 / 未识别）
                                      └ 失败：轻提示错误原因，不保存
导出 / 模板 → 浏览器下载 CSV → 轻提示
切维度 / 月份 → 全局维度改变，所有业财页面同步
清空手工覆盖 → clearAllMonthlyOverrides → commit('indicators')
恢复示例数据 → 确认弹窗（取消 / 确认恢复）→ API-F15-03 → 重新读取 API-F15-01 → 提示「已恢复示例数据」
```

## 11. 原型与待确认
- 原型 `PAGE-F15-09.html`：粘贴导入按编码粗略识别以示意结果提示；下载 / 导出只出轻提示；恢复示例数据含确认弹窗。
- 与 FLOW-40 的差异：FLOW-40 期望导入后财务指标页「示例数据」标记消失；实现中标记只要任一部分仍为示例（如政策环境未保存过）就继续显示，需确认按页 / 按部分判断还是维持现状。
- 实现现状：导出与模板文件名仍带原工具的公司简称前缀，建议改为中性名称（如「业财指标_年度口径_全部_<时间>.csv」）。
