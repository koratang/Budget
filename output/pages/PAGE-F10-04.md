## 2. 页面概述

### 2.1 一句话定位
按部门和预算科目看费用花得比时间快还是慢，一眼找出超进度和超预算的科目。

### 2.2 存在理由
1. 部门费用是固定费用的主体，部门费用增速不能超过收入增速（PRD §6.2），需要逐科目追踪。
2. 年内一次性支出（展会、软件年费）会让使用率跳升，需要配说明，避免误判。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 识别 | 超时间进度 10 个百分点、超全年预算的科目 100% 着色 |
| 一致 | 全公司累计实际与 PAGE-F10-01 部门费用合计一致 |

### 2.4 不做什么
- **不做**月度明细与月份选择——AC-F10-07 固定为截至最近导入月累计。
- **不做**费用申请审批——本期明确不做独立费用审批流。
- **不做**专项预留额度的使用登记——在 PAGE-F05-02。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 财务负责人 林晓、财务BP 陈思雨、各部门负责人（如人力资源部 吴静）、部门预算专员 |
| 频次 | 每月金蝶导入后 |

**场景 A**：林晓看到市场部合计使用率 44.4%（琥珀），展开发现展会费 103.1%（红），该科目行的说明写明 4 月 KBIS 展会一次性支付。
**场景 B**：吴静打开本页，只看到人力资源部 5 个科目和「合计（我的部门）」。

## 5. 界面内容

### 5.1 主表列（AC-F10-07）

| 列 | 说明 |
| :--- | :--- |
| 部门（冻结） | 部门合计行带展开/收起按钮 |
| 预算科目 | 部门合计行写「部门合计」 |
| 全年预算 | 最新调整后目标（无调整时为年初原始目标）的全年金额，含已计入科目的专项预留额度（DEC-F10-03、DEC-F10-06） |
| 累计实际 | 1 月至最近导入月金蝶实际，按科目映射归集 |
| 额度使用率 | 累计实际 ÷ 全年预算，1 位小数 |
| 时间进度 | 最近导入月份数 ÷ 12（2027-04 时为 33.3%） |
| 达成条 | 填充 = 使用率（0–120% 映射到条宽），刻度线 = 时间进度 |
| 偏差说明 | 在预算科目行（部门合计行不填）；规则同 PAGE-F10-02 §5.5，键为 月份 × 部门 × 预算科目（DEC-F10-06） |

着色（费用类）：使用率超过时间进度 10 个百分点（> 43.3%）琥珀；超过 100% 红；其余深灰。使用率文字同色。

### 5.2 筛选
部门：「全部」+ 用户范围内部门；只有一个部门时不显示「全部」。

## 6. 交互流程

```
打开 → 默认全部部门展开
  ├─ 点部门箭头 → 收起/展开该部门科目
  ├─ 选部门 → 只显示该部门
  ├─ 财务BP 在部门合计行「填写说明」→ 弹窗 → 保存
  └─「导出 Excel」→ 下载 → 轻提示
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 已导入金蝶实际 | 卡片 + 主表 |
| 空 | 本年度没有金蝶实际 | 「2027 年还没有导入金蝶实际」；财务BP 见「去导入实际数」→ PAGE-F09-01 |
| 加载 | 请求中 | 卡片与表格骨架，导出禁用 |
| 错误 | 请求失败 | 「部门费用报告加载失败」+「重试」 |
| 无权限 | 未被分配任何部门 | 「无权限」+「返回工作台」 |

| 边界 | 处理 |
| :--- | :--- |
| 全年预算为 0 但有实际 | 使用率显示「—」，累计实际正常显示 |
| 科目无实际 | 累计实际 0.00，使用率 0.0% |
