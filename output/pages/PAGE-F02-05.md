## 2. 页面概述

### 2.1 一句话定位

录入每个预算年度一币一值的预算汇率（年初原始目标锁定后冻结），以及每月各币种的当月平均汇率，让双币金额、汇率差与 BI 核对有统一依据。

### 2.2 存在理由

1. 渠道、店铺、B端客户的收入按本币填报，需按年度预算汇率折算为人民币（AC-F02-06、PRD §3.2.1）。
2. 缺预算汇率会阻止填报提交（AC-F02-07），财务BP 需要看到缺哪个币种。
3. 偏差报告中的汇率差与 BI 和金蝶核对依赖当月平均汇率（AC-F02-08、AC-F09-07）。
4. 原始目标锁定后预算汇率若可改，会让已锁定的人民币目标被重算，因此锁定后冻结（AC-F02-11）。

### 2.3 不做什么

- 不自动抓取外部汇率：需求规定由财务BP 录入（PRD §3.2.1）。
- 不在本页显示折算结果或汇率差：结果在填报与偏差报表中显示。

## 3. 用户与场景

- **场景 A：编制前录预算汇率**：2026-10，财务BP 选择预算年度 2027，按 2026-09-30 中国银行中间价录入 USD 7.1200、CAD 5.2400、EUR 7.7900、GBP 9.3100（示例值，以财务BP录入为准）。
- **场景 B：月度录当月平均汇率**：BI 2027-03～04 批次导入后，财务BP 录入 4 月各币种当月平均汇率；页面提示「2027-04 GBP」尚未录入。
- **场景 D：锁定后查看**：2027 年初原始目标已于 2026-12-28 经 CEO 审批锁定，财务BP 打开 2027 年度预算汇率只能查看，页面显示「已随年初原始目标锁定」（AC-F02-11）。
- **场景 C：新币种**（编制期，原始目标未锁定）：B端新客户用 AUD 结算 → 本页显示 AUD 缺少预算汇率 → 补录后相关填报才能提交。锁定后新增币种的处理见待确认 Q6。

## 4. 信息架构

1. 页头：标题
2. 标签页：年度预算汇率 | 月度实际汇率

4. 实际标签：说明 + 缺当月平均汇率提示条（仅有缺失时）+ 月份 × 币种表 + 编辑说明

## 5. 界面内容

### 5.1 年度预算汇率

| 元素 | 内容 |
| :--- | :--- |
| 预算年度 | 下拉，默认当前编制 / 执行年度（2027） |
| 口径说明 | 「口径：2026-09-30 中国银行人民币外币汇率中间价 · 1 单位外币折合人民币 · 示例值，以财务BP录入为准」（PRD §3.2.1） |
| 锁定提示条 | 该年度年初原始目标已经 CEO 审批锁定时显示：「已随年初原始目标锁定：{年度} 年度年初原始目标已于 YYYY-MM-DD 经 CEO 审批锁定，该年度各币种预算汇率不可修改。」（AC-F02-11） |
| 提示条 | 全部齐全：「2027 年度店铺与 B端客户使用的 N 个币种均已录入预算汇率。」；有缺失：「缺少预算汇率：AUD。涉及这些币种的填报将无法提交，提交时会提示缺少汇率的币种代码。」（琥珀） |

表格列：

| 列 | 内容 |
| :--- | :--- |
| 币种 | 代码 USD / CAD / EUR / GBP |
| 名称 | 美元 / 加拿大元 / 欧元 / 英镑 |
| 预算汇率（CNY） | 4 位小数，等宽右对齐，单元格内编辑；空时显示「未录入」；已锁定年度为只读单元格（AC-F02-11） |
| 使用该币种的店铺 / 客户 | 如「6 个店铺、2 个 B端客户」，币种清单由店铺与 B端客户的结算币种决定 |
| 状态 | 已录入（绿）/ 缺少汇率（红）；已锁定年度另显示「已随年初原始目标锁定」 |
| 最近修改 | 日期 + 修改人 |

### 5.2 月度实际汇率（当月平均汇率）

- 标签页名称保留「月度实际汇率」，录入值为各币种的当月平均汇率（AC-F02-08）。
- 说明：「2027 年 · 当月平均汇率 · 1 单位外币折合人民币 · 用于把该月 BI 本币实际收入折算为人民币、计算汇率差，以及 BI 与金蝶核对」。
- 表格：行 = 2027-01～2027-12；列 = USD、CAD、EUR、GBP 当月平均汇率（4 位小数，单元格内编辑）+「BI 数据」（已导入 / —）。
- 提示条：「已导入 BI 数据但缺少当月平均汇率：2027-04 GBP。补录前该月 BI 本币收入无法折算为人民币，偏差报告该月汇率差显示「缺少 2027-04 汇率」。」（DEC-F02-09）

## 6. 交互流程

```
预算汇率单元格（仅所选年度年初原始目标未锁定时可编辑）：点击 → 输入 → 离开单元格（或回车）
   ├─ 格式不对 → 单元格标红 +「请输入大于 0 的数字，最多 4 位小数」
   ├─ 原本为空 → 直接保存 → 轻提示「已保存 {币种} 预算汇率 x」
   └─ 原本有值 → 确认弹窗「{币种} 预算汇率由 a 改为 b。确认后，{年度} 年度所有 {币种} 预算金额将按新汇率重新折算为人民币。」
         ├─ 取消 → 恢复原值
         └─ 确认修改 → 保存 → 轻提示「…预算金额已重新折算」（AC-F02-06）
当月平均汇率单元格：点击 → 输入 → 离开即保存；格式不对标红；清空视为未修改
已锁定年度：预算汇率单元格只读，不响应编辑（AC-F02-11）
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 汇率格式 | 离开单元格 | 大于 0，最多 4 位小数（DEC-F02-09） | 请输入大于 0 的数字，最多 4 位小数 |
| 锁定冻结 | 编辑预算汇率 | 该年度年初原始目标已锁定时不可修改 | 单元格只读 + 锁定提示条（AC-F02-11） |

- 预算汇率按年度一币一值，用于折算该年度所有该币种的预算金额（AC-F02-06）。
- 填报涉及的币种在该预算年度无预算汇率时，填报提交被阻止并提示缺少的币种代码（AC-F02-07，提示出现在填报页，本页给出缺失清单）。
- 当月平均汇率用于把该月 BI 本币实际收入折算为人民币并计算汇率差（AC-F02-08），也用于 BI 与金蝶核对（AC-F09-07）。
- 年初原始目标经 CEO 审批锁定后，该年度预算汇率冻结（AC-F02-11）。
- 缺当月平均汇率时，偏差报告该月汇率差显示「缺少 YYYY-MM 汇率」（DEC-F02-09）。
- 金额折算结果四舍五入保留 2 位小数（PRD §3.2.1）。
