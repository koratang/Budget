## 2. 页面概述

### 2.1 一句话定位

维护预算、金蝶、BI 共用的「渠道 → 店铺 → 站点 → 币种」口径，并标出处于 12 个月保护期的新渠道。

### 2.2 存在理由

1. 填报和导入都按店铺校验，店铺不在基础数据中会导致导入整份失败（AC-F09-01）。
2. 新渠道需单独适用保守放量规则（REQ-F13-01），标记是规则生效的前提。

### 2.3 不做什么

- 不做店铺删除：需求只有启用 / 停用（AC-F02-10）。
- 不在本页设置放量上限数值：上限在规则库 `PAGE-F12-01.html` 维护（PRD §3.3.13）。
- 不做与金蝶 / BI 的自动名称比对：AC-F02-02 只要求重名拒绝。

## 3. 用户与场景

- **场景 A：新开店铺**：Amazon 新开日本站 → 财务BP 新增店铺（渠道 Amazon、店铺名称、站点、币种）→ 保存后填报与导入中可选用（AC-F02-01）。
- **场景 B：关店**：某店铺关闭 → 财务BP 设为停用 → 新预算填报不再列出，历史实际仍可导入（AC-F02-10）。
- **场景 C：新渠道**：开通 TikTok Shop → 财务BP 新增渠道与店铺 → 财务负责人标记为新渠道，起始月 2027-03 → 2027-03～2028-02 按新渠道处理，2028-03 起自动转常规（AC-F13-01）。

## 4. 信息架构

1. 页头：标题 + 「新增渠道」「新增店铺」（仅财务BP）
2. 筛选栏：渠道、状态、只看新渠道；右侧提示「店铺名称须与金蝶辅助核算、BI 中的店铺名称一致」
3. 店铺列表（按渠道分组）+ 合计行「共 N 个渠道 · M 个店铺（启用 x，停用 y）」
4. 店铺抽屉（新增 / 编辑；财务负责人视角为新渠道标记）
5. 弹窗：新增渠道、渠道级新渠道标记（财务负责人）、停用确认

原型顶部可切换「财务BP / 财务负责人」视角与四种状态，虚线框标注「原型说明，非产品功能」。

## 5. 界面内容

### 5.1 列表字段

| 列 | 内容 |
| :--- | :--- |
| 渠道 | 渠道名，同渠道只在首行显示；财务负责人视角附「渠道标记」按钮 |
| 店铺名称 | 等宽显示，如 Amazon-US-01 |
| 站点 | 美国 / 加拿大 / 英国 / 德国 … |
| 结算币种 | 币种代码 USD / CAD / GBP / EUR |
| 状态 | 启用 / 停用徽章；停用行文字置灰 |
| 新渠道 | 新渠道期内：「新渠道」徽章 + 「起始月～到期月」，渠道级标记注明「（渠道级）」；已满 12 个月：「已转常规（YYYY-MM 满 12 个月）」；未标记：— |
| 操作 | 财务BP：「编辑」；财务负责人：「设置新渠道」 |

### 5.2 店铺抽屉字段

| 字段 | 必填 | 规则 | 财务BP | 财务负责人 |
| :--- | :--- | :--- | :--- | :--- |
| 所属渠道 | 是 | 从渠道列表选择 | 可编辑 | 只读 |
| 店铺名称 | 是 | 不能与已有店铺重名；提示「与金蝶、BI 中的店铺名称一致」 | 可编辑 | 只读 |
| 站点 | 是 | 下拉 | 可编辑 | 只读 |
| 结算币种 | 是 | 下拉；所选币种在当前预算年度无预算汇率时，字段下方提示「2027 年度尚无该币种的预算汇率，涉及该币种的填报将无法提交。去汇率页补录」（链接 `PAGE-F02-05.html`，依据 AC-F02-07） | 可编辑；店铺已被填报或导入使用后只读（DEC-F02-03） | 只读 |
| 状态 | 是 | 启用 / 停用；说明「停用后新预算填报不再列出该店铺；历史实际导入仍接受该店铺的数据」 | 可编辑 | 只读 |
| 新渠道标记 | — | 勾选「标记为新渠道」后必填起始月；实时提示「将于 起始月 至 到期月 按新渠道处理，次月起自动转为常规渠道」 | 只读文字「由财务负责人设置」 | 可编辑；店铺已随渠道标记时只读显示「随渠道 X 标记」 |

### 5.3 弹窗

- **新增渠道**（财务BP）：渠道名称（必填，不可与已有渠道重名，DEC-F02-02）。
- **改名确认**（财务BP，店铺已被填报或导入使用时修改名称）：「将「{原名}」改名为「{新名}」？该店铺已被填报或导入使用，新名称须与金蝶辅助核算、BI 中的店铺名称一致，否则之后的导入无法匹配该店铺。」按钮「取消」「确认改名」（DEC-F02-03）。
- **渠道级新渠道标记**（财务负责人）：说明「标记在渠道上时，该渠道下全部店铺按新渠道处理」；勾选 + 起始月。
- **停用确认**：「停用后，{店铺} 不再出现在新预算填报中；历史实际导入仍接受该店铺的数据。」按钮「取消」「确认停用」。

## 6. 交互流程

```
财务BP 点「新增店铺」→ 抽屉 → 填写 → 保存
   ├─ 必填缺失 → 字段旁「请选择所属渠道 / 请填写店铺名称 / 请选择站点 / 请选择结算币种」
   ├─ 名称重复（不区分大小写）→ 「店铺名称已存在」（AC-F02-02）
   └─ 通过 → 轻提示「已新增店铺 X，填报与导入中可选用」（AC-F02-01）
财务BP 编辑店铺并把状态由启用改为停用 → 停用确认弹窗 → 确认 → 保存（AC-F02-10）
财务负责人 点「设置新渠道」或「渠道标记」→ 勾选 + 起始月 → 保存
   ├─ 勾选但未选起始月 → 「请选择起始月」
   └─ 通过 → 列表显示「新渠道」与期间（AC-F13-01）；取消勾选即取消标记
```

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有渠道与店铺 | 列表 |
| 空 | 尚无任何渠道 | 「还没有渠道和店铺」+「先新增渠道，再在渠道下新增店铺；店铺会出现在预算填报和实际数导入的校验中。」+「新增渠道」 |
| 筛选无结果 | 筛选无匹配 | 「没有符合条件的店铺 · 调整筛选条件后再试」 |
| 加载 | 请求中 | 骨架行 |
| 错误 | 请求失败 | 「渠道与店铺加载失败 · 网络异常或服务暂时不可用，请重试」+ 重试 |
| 只读 | CEO 访问 | 列表与筛选可用，无新增、编辑、标记入口，操作列显示「只读」（DEC-F02-01） |
| 无权限 | 非财务BP / 财务负责人 / CEO 访问 | 「无权限 · 渠道与店铺由财务BP 维护，新渠道标记由财务负责人设置」+ 返回工作台 |

| 边界 | 处理 |
| :--- | :--- |
| 新渠道满 12 个月 | 系统自动转为常规，列表显示「已转常规」，无需人工操作（AC-F13-01） |
| 停用店铺 | 新预算填报不列出；实际导入仍接受（AC-F02-10）；角色与权限的范围选项仍可见 |
| 店铺已用于填报或导入后改名 | 保存前二次确认，提示须与金蝶 / BI 名称一致（DEC-F02-03） |
| 店铺已用于填报或导入后改币种 | 结算币种字段只读，提示「该店铺已被填报或导入使用，结算币种不可修改」（DEC-F02-03） |

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 店铺名称唯一 | 保存 | 与已有店铺不重名 | 店铺名称已存在 |
| 必填 | 保存 | 渠道、名称、站点、币种 | 见 §6 |
| 起始月 | 保存 | 标记新渠道时必填 | 请选择起始月 |

- 新渠道期 = 起始月起 12 个月（含起始月），满 12 个月后自动转为常规渠道（AC-F13-01）。
- 新渠道的放量上限与超限标注在填报页 `PAGE-F04-02.html` 生效（AC-F13-02），本页只负责标记。
