## 2. 页面概述

### 2.1 一句话定位

看一条规则当前生效什么、正在审批什么、历史上改过什么；需要改时提交新版本走审批。

### 2.2 存在理由

1. 预警规则要可配置，阈值和接收人不能写死（AC-F12-02）。
2. 规则只出新版本，评估只认生效版本，历史可追溯（AC-F12-04、AC-F12-05、AC-F12-06、NFR-004）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 字段完整 | 预警规则表单含 AC-F12-02 全部 6 个字段 |
| 追溯 | 版本历史列出全部版本的内容、可信度、依据、提交人、审批人、生效时间（AC-F12-06） |

### 2.4 不做什么

- 不在本页审批——审批在 PAGE-F07-02。
- 不删除规则或版本；不直接修改生效版本。

## 3. 用户与场景

**场景 A：查看有待审批版本的预警规则**：「部门费用额度使用率超出时间进度 10 个百分点以上」——左卡生效 v1（阈值 10 个百分点，未验证经验），右卡待审批 v2（阈值 8 个百分点，历史观察，依据为 2026 年金蝶回测）；提示「预警评估只使用生效版本 v1；待审批的 v2 在审批通过前不参与评估」。

**场景 B：查看有历史版本与已退回版本的驱动假设**：「Amazon 美国站 11 月销量为 10 月的 1.6 倍」——生效 v2；v3（1.8 倍）被林晓退回，卡片显示退回原因「只有经验判断，没有历史数据支撑 1.8 倍…」，状态「已退回，不生效；v2 继续生效」；按钮「修改后重新提交」进入编辑，提交后生成 v4（AC-F12-07）；版本历史中 v1（1.4 倍，未验证经验）为历史。

**场景 C：新建预警规则**：陈思雨选类型「预警规则」，选指标「毛利率差」（单位自动显示「个百分点」）、比较方式「低于」、阈值、连续月数、适用对象、接收角色，选可信度、填依据 → 提交审批。

## 4. 信息架构

**查看模式**
1. 头部卡片：类型、版本状态徽章（生效 vN / 待审批 vN / 已退回 vN）、规则名称、评估说明、「编辑并提交新版本」（有已退回版本时为「修改后重新提交」；不可用时旁注原因）
2. 卡片：生效版本、待审批版本或已退回版本（含退回人、时间、原因，AC-F12-07）
3. 版本历史表

**新建 / 编辑模式**
1. 类型（单选）、规则名称
2. 预警规则字段区（仅类型为预警规则时）
3. 规则内容（驱动假设、额度标准时）
4. 可信度状态（单选，无默认）、依据
5. 审批路径说明；取消 / 提交审批

## 5. 界面内容

### 5.1 预警规则字段（AC-F12-02）

| 字段 | 选项 / 输入 | 说明 |
| :--- | :--- | :--- |
| 指标 * | 收入达成率 / 毛利率差 / 额度使用率减时间进度 / 额度使用率 / 预测偏差百分点 | 选择后阈值单位自动为「%」或「个百分点」 |
| 比较方式 * | 低于 / 高于 / 低于等于 / 高于等于 | DEC-F12-01 |

### 5.2 公共字段

| 字段 | 说明 |
| :--- | :--- |
| 类型 * | 驱动假设 / 预警规则 / 额度标准 |

### 5.3 版本历史列（AC-F12-06）

版本、状态（待审批 / 生效 / 历史）、内容、可信度、依据、提交人、审批人、生效时间。

## 6. 交互流程

```
查看规则 → 生效版本 / 待审批版本 / 版本历史
编辑并提交新版本 → 表单预填当前内容 → 修改
提交审批
   ├─ 必填缺失 → 各字段旁提示，定位到第一个错误，不提交
   └─ 通过 → 保存为待审批新版本
            ├─ 驱动假设 / 预警规则：财务负责人审批
            └─ 额度标准：财务负责人 → CEO
            审批通过 → 新版本生效，原生效版本转历史（AC-F12-04）
预警评估只使用生效版本（AC-F12-05）
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 查看 | 打开已有规则 | 卡片 + 版本历史 |
| 编辑 / 新建 | 点编辑或新建 | 表单 |
| 校验失败 | 必填缺失或格式错误 | 字段标红 + 提示 |
| 空 | 规则不存在 | 「该规则不存在」+ 返回规则库 |
| 加载 | 请求中 | 骨架行 |
| 错误 | 请求失败 | 「数据加载失败」+ 重试 |
| 无权限 | 非财务BP / 财务负责人 / CEO | 无权限提示；CEO 无编辑按钮 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 已有待审批版本时再编辑 | 禁用「编辑并提交新版本」并说明「已有待审批版本 vN，审批完成前不能再提交新版本」（DEC-F12-01） |
| 版本被退回 | 版本状态「已退回」且不生效，显示退回原因；「修改后重新提交」生成新版本（AC-F12-07） |
| 切换类型 | 预警规则字段与规则内容字段互相切换显示 |

## 8. 业务规则与校验

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 规则名称 | 提交时 | 非空 | 「请填写规则名称」 |
| 指标 / 比较方式 / 适用对象 | 提交时（预警规则） | 已选择 | 「请选择指标」「请选择比较方式」「请选择适用对象」 |
| 阈值 | 提交时（预警规则） | 数字 | 「请填写阈值（数字）」 |
| 连续月数 | 提交时（预警规则） | ≥ 1 整数 | 「请填写不小于 1 的整数」 |
| 接收角色 | 提交时（预警规则） | 至少一个 | 「请至少选择一个接收角色」 |
| 规则内容 | 提交时（驱动假设、额度标准） | 非空 | 「请填写规则内容」 |
| 可信度状态 | 提交时 | 必须选择 | 「请选择可信度状态」（AC-F12-01） |
| 依据 | 提交时 | 非空 | 「请填写依据」 |

- 审计：规则库每次修改记录操作人、时间、前后值，≥ 3 年（NFR-004）。
