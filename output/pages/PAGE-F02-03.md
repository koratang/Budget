## 2. 页面概述

### 2.1 一句话定位

维护 B端客户（归哪个业务部门、用什么币种结算）和公司部门清单，让 B端填报、部门费用与金蝶导入用同一套名称。

### 2.2 存在理由

1. B端填报按「月 × B端客户」进行，客户不在清单中就无法出现在负责部门的填报里（AC-F02-09）。
2. 部门是部门费用预算、审批与金蝶导入校验的维度（PRD §3.2.1、AC-F09-01）。

### 2.3 不做什么

- 不在本页指定部门负责人、预算专员或客户的负责业务员：在 `PAGE-F01-02.html` 分配，本页只读显示。
- 不做客户或部门删除：只可停用（DEC-F02-06）。

## 3. 用户与场景

- **场景 A：新签 B端客户**：外贸部签下 Bauhaus → 财务BP 新增客户（负责部门外贸部、币种 EUR）→ 外贸部 B端填报出现该客户（AC-F02-09）。
- **场景 B：组织调整**：新成立部门 → 财务BP 新增部门 → 财务负责人在角色与权限中指定负责人和预算专员。

## 4. 信息架构

1. 页头：标题
2. 标签页：B端客户 | 部门
3. 客户标签：统计（共 N 个 · 美国业务部 x · 外贸部 y）+「新增客户」+ 客户表 + 说明「B端业务负责人取自角色与权限中分配了该客户范围的员工」
4. 部门标签：统计 +「新增部门」+ 部门表 + 说明与「角色与权限」链接
5. 新增 / 编辑弹窗

## 6. 交互流程

```
「新增客户」→ 弹窗 → 填写 → 保存
   ├─ 必填缺失 → 「请填写客户名称 / 请选择负责部门 / 请选择结算币种」
   ├─ 客户名称重复 → 「客户名称已存在」
   └─ 通过 → 轻提示「已新增客户 X，已加入 {部门} 的 B端填报」（AC-F02-09）
「新增部门」→ 弹窗 → 填写名称 → 保存 → 轻提示「已新增部门 X，请在角色与权限中指定负责人」
```

Esc 或「取消」关闭弹窗不保存。

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有数据 | 两个标签页 |
| 空 | 尚无 B端客户 | 「还没有 B端客户」+「新增客户并指定负责部门与结算币种后，该客户会出现在负责部门的 B端填报中。」+「新增客户」 |
| 加载 | 请求中 | 骨架行 |
| 错误 | 请求失败 | 「数据加载失败 · 网络异常或服务暂时不可用，请重试」+ 重试 |
| 只读 | CEO、财务负责人访问 | 两个标签页可查看，无新增与编辑入口，操作列显示「只读」（DEC-F02-01） |
| 无权限 | 非财务BP / CEO / 财务负责人访问 | 「无权限 · B端客户与部门清单由财务BP 维护」+ 返回工作台 |

| 边界 | 处理 |
| :--- | :--- |
| 客户改了负责部门 | 待确认 Q3 |
| 客户或部门停用 | 不进入新的填报；历史预算与实际保留并照常出现在报表（DEC-F02-06） |
| 客户无人负责 | 显示「未分配」，提醒在角色与权限中给 B端业务分配该客户 |

## 8. 业务规则

- 负责部门只能是美国业务部或外贸部（AC-F02-09）。
- 客户名称、部门名称唯一；可停用不可删除（DEC-F02-06）。
- 部门清单手工维护，不与钉钉组织架构同步（PRD §3.3.2）。
- 客户与部门的人员关系不在本页维护，只读引用角色与权限（REQ-F01-02）。
