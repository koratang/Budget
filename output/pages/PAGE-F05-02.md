## 2. 页面概述

### 2.1 一句话定位

为培训、年会、团建等临时活动提前预留额度，并按金蝶凭证跟踪用了多少、还剩多少。

### 2.2 存在理由

1. 临时大额费用缺少历史参考，过去没有额度可管（US-F05-01）。
2. 专项金额要进入部门预算，同时要能看到实际使用（AC-F05-03、AC-F05-05）。

### 2.3 页面目标

| 目标维度 | 具体指标 |
| :--- | :--- |
| 预算一致 | 新增专项后 PAGE-F05-01 对应科目、月份预算同步增加 |
| 余额准确 | 剩余金额 = 预留金额 − 已用金额，登记后立即更新 |

### 2.4 不做什么

- 不做专项的申请审批流程（PRD §3.3.5，用户访谈 OQ-3）。
- 不做专项编辑与删除——需求未定义。
- 部门预算专员不能登记使用；财务BP 不新增专项（需求分别指定）。

## 3. 用户与场景

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 部门预算专员（郑可，人力资源部）；财务BP（陈思雨，可看全部部门 AC-F01-10） |
| 使用时机 | 编制期新增专项；执行期活动发生后登记使用 |

**场景 B（执行期 2027-05-12）**：陈思雨在训练营结束后登记「2027-04-22 · 96,000.00 · 记-2027-04-0233」→ 已用、剩余更新。

## 5. 界面内容

### 5.1 元素清单

**专项列表**

| 列 | 内容 | 依据 |
| :--- | :--- | :--- |
| 专项名称 | 如「2027 年会」 | AC-F05-03 |
| 所属预算科目 | 如「员工福利费」 | AC-F05-03 |
| 计划月份 | YYYY-MM | AC-F05-03 |
| 预留金额 | 260,000.00 | AC-F05-03 |
| 已用金额 | 登记使用之和 | AC-F05-05 |
| 剩余金额 | 预留 − 已用；为负时显示为不利色 | AC-F05-05 |
| 上年同科目全年实际 | 所属科目 2026 年全年实际；编制期列名为「上年同科目实际（2026-01～11，12 月未导入）」；无历史显示「无历史数据」 | AC-F05-04 |
| 操作 | 财务BP：「登记使用」「明细（n）」；部门预算专员：— | AC-F05-05 |

- 原型数据（人力资源部）：2027 年会 · 员工福利费 · 2027-01 · 260,000.00；管理层领导力训练营 · 培训费 · 2027-04 · 180,000.00；夏季团建 · 员工福利费 · 2027-07 · 90,000.00。
- 执行期已用：年会 248,600.00（记-2027-01-0186），训练营 96,000.00（记-2027-04-0233）。员工福利费 2026 全年实际 469,400.00，培训费 69,000.00。
- 市场部（财务BP 切换）：KBIS 2027 厨卫展 预留 420,000.00、已用 437,800.00、剩余 −17,800.00（不利色）。

**明细（展开行）**：使用日期、金额、金蝶凭证号。

**新增专项弹窗（AC-F05-03）**
- 字段：专项名称*、所属预算科目*（本部门预算科目下拉）、计划月份*（2027-01～2027-12）、预留金额（人民币）*。
- 选科目后显示参考：「参考：培训费 2026 年 1–11 月实际 ¥ 59,900.00」（AC-F05-04）。
- 按钮：取消 /「保存并计入预算」。

**登记使用弹窗（AC-F05-05）**
- 顶部：预留、已用、剩余。
- 字段：使用金额（人民币）*、使用日期*、金蝶凭证号*。按钮：取消 /「登记」。

### 5.2 辅助信息

「专项金额计入所属科目在计划月份的部门预算（见 部门费用填报）。剩余金额 = 预留金额 − 已用金额；已用金额由财务BP 按金蝶凭证登记。」

## 6. 交互流程

```
新增专项（部门预算专员）
  → 校验 → 保存 → 列表新增一行；PAGE-F05-01 该科目该月「专项预留」与科目合计增加
  → 轻提示「已新增「管理层领导力训练营」，¥ 180,000.00 已计入培训费 2027-04 预算」

登记使用（财务BP）
  → 校验 → 保存 → 已用 += 金额，剩余 = 预留 − 已用 → 轻提示「已登记，{专项} 剩余 ¥ x」
```

- 部门费用填报已提交（锁定）时：隐藏「新增专项」，提示「人力资源部 2027 年度费用预算已提交，内容已锁定，被退回之前不能新增专项。」（DEC-F05-03，源自 AC-F04-09：专项计入部门预算，锁定期间不得改变预算）

## 7. 状态与边界

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 加载 | 进入页面 | 骨架行「正在加载专项预留额度…」 |
| 空 | 本部门还没有专项 | 「还没有专项预留额度」「培训、年会、团建等临时活动可以提前预留额度，金额会计入所属科目当月预算。」+「新增专项」 |
| 错误 | 网络或服务异常 | 「专项预留额度加载失败」+「重试」 |
| 无权限 | 访问非被分配部门（AC-F01-06、AC-F01-11） | 「无权限」「你只能查看被分配部门的专项预留额度。如需开通，请联系财务负责人。」 |
| 锁定 | 部门费用单位已提交或已通过 | 隐藏「新增专项」，显示锁定提示 |

| 边界场景 | 处理策略 |
| :--- | :--- |
| 登记金额超过剩余 | 允许登记，剩余显示负数（不利色）（DEC-F05-04） |
| 科目无历史实际 | 上年同科目全年实际显示「无历史数据」 |
