## 2. 页面概述

### 2.1 一句话定位

任选两个预算版本，按维度看收入、毛利和净利润差了多少、差在哪里。

### 2.2 存在理由

1. 季度调整后管理层要知道「改了什么、改了多少」（REQ-F08-03）。
2. 原始目标、调整后目标、滚动快照并存，必须能两两对照才能解释偏差来源。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 覆盖 | 任意两个版本均可对比（AC-F08-08） |
| 权限 | 结果 100% 按用户数据范围过滤（NFR-003） |
| 一致 | 各维度行差额之和等于合计行差额 |

### 2.4 不做什么

- 不对比实际数——实际与预算的偏差在 F10 报表。
- 不分摊公共费用到渠道——与 PRD OQ-8 一致，净利润只在公司合计层显示。
- 不修改任何版本。

## 3. 用户与场景

**场景 A：看 Q1 调整改了什么**：林晓从版本列表勾选 V1 与 V2 → 对比 → 关键数显示公司收入 −¥ 600,000.00、毛利与净利润 −¥ 126,000.00 → 表格看到 Wayfair-US-01 下调 ¥ 4,200,000.00、Amazon-US-01 与 HomeDepot-US-01 上调。

**场景 B：按品类看**：切换维度为「品类 × 新品/老品」查看平台渠道收入、毛利差额。

## 4. 信息架构

1. 选择行：版本 A、版本 B、维度（渠道 × 店铺 × 站点 / 品类 × 新品/老品 / B端客户）、期间说明（全年 1–12 月）、导出 Excel
2. 范围说明：「按你的数据范围显示：…。差额 = 版本 B − 版本 A」
3. 关键数（3 个）：公司收入差额、公司毛利差额、公司净利润差额，各附 A、B 两版本值
4. 对比表：维度列 + 收入（A、B、差额）+ 毛利（A、B、差额），末行合计
5. 口径说明：净利润公式与不分摊说明；表格末行「公司合计（含 B端、部门费用与公司层其他损益）」列出两版本净利润及差额，维度行与维度合计行的净利润列显示「—」（AC-F08-08）

## 5. 界面内容

### 5.1 元素清单

| 元素 | 内容 | 说明 |
| :--- | :--- | :--- |
| 版本选择 | 年度内全部版本：年初原始目标、各调整后目标、各季度滚动预测快照 | 默认取 URL 参数，否则 V1 对比当前目标 |
| 维度 | 渠道 × 店铺 × 站点（店铺 · 站点为主，渠道小字）；品类 × 新品/老品（平台渠道）；B端客户（含所属部门与币种） | — |
| 关键数 | 差额为负时以不利色显示 | 净利润 = 平台渠道毛利 + B端毛利 − 部门费用 + 公司层其他损益 |
| 对比表 | 金额 ¥ 千分位 2 位小数，等宽右对齐；差额带正负号，负数以不利色显示，无差额显示「—」 | 冻结维度列 |
| 导出 Excel | 按当前选择导出 | 表格页通用（蓝图 §5） |

## 6. 交互流程

```
进入页面（带 a、b 参数或默认）
   │
   ├─ A = B → 显示「请选择两个不同的版本」，隐藏结果
   └─ A ≠ B → 按数据范围计算各维度组合两版本的收入、毛利及差额
              + 公司层净利润差额（AC-F08-08）
切换版本 / 维度 → 即时刷新；URL 同步，便于分享
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 两个不同版本 | 关键数 + 对比表 |
| 选择无效 | 两个下拉选了同一版本 | 不利色提示「请选择两个不同的版本」 |
| 空 | 年度不足两个版本 | 「至少需要两个预算版本才能对比」+ 返回版本管理 |
| 加载 | 计算中 | 骨架行 |
| 错误 | 请求失败 | 「数据加载失败」+ 重试 |
| 无权限 | 无预算查看权限 | 无权限提示 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 某维度组合只在一个版本中存在（如新渠道起始月后才有数） | 缺失侧按 0 计，差额照常 |
| 数据范围受限的用户 | 只列其范围内的维度组合；合计为范围内合计 |

## 8. 业务规则与校验

- 差额 = 版本 B − 版本 A；金额四舍五入 2 位小数（AC-F06-09 口径）。
- 服务端按数据范围过滤（NFR-003）。
