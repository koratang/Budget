## 2. 页面概述

### 2.1 一句话定位

财务BP 把金蝶和 BI 的 Excel 传进系统：有一行错就整份不进并逐行说明；对了才入库，重复期间要确认覆盖并留下旧记录。

### 2.2 存在理由

1. 预算与实际要在同一口径对比（US-F09-01）；部分写入的数据比没有数据更危险（AC-F09-01）。
2. 首次使用需要 24 个月历史数据做历史参考和同比（AC-F09-04）。
3. 导入是审计对象，覆盖后必须能追溯旧文件（AC-F09-03、NFR-004）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 校验时效 | 5 万行以内文件，上传完成到显示校验结果 ≤ 60 秒（NFR-002） |
| 原子性 | 校验有任一问题的文件写入行数 = 0（AC-F09-01、AC-F09-05） |
| 可追溯 | 被覆盖的导入 100% 保留文件名、导入人、导入时间（AC-F09-03） |

### 2.4 不做什么

- 不做在线修改问题行——修正源文件或主数据后整份重传。
- 不做金蝶 / BI 接口自动取数——本期只用 Excel（PRD OQ-10）。
- 不提供删除导入记录（NFR-004）。
- 不在本页展示核对结果——见 PAGE-F09-02。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 财务BP 陈思雨 |
| 频次 | 金蝶每月关账后一次（约次月第 18 个工作日）；BI 每两个月一次；历史数据首次使用时一次 |

### 3.2 核心使用场景

**场景 A：金蝶月度校验未通过**：上传「金蝶_2027-04_利润表_v2.xlsx」→ 显示「校验未通过，本文件没有写入任何数据。共 6 个问题行」→ 按问题类型汇总徽章 → 表格逐行列出行号、问题类型、涉及编码或名称、处理方式（链接到对应主数据页）。

**场景 B：金蝶月度重复期间覆盖**：校验通过 → 摘要（期间、文件、行数、收入合计、成本费用合计）+ 未归属渠道明细 → 提示「2027-04 已有导入数据：金蝶_2027-04_利润表.xlsx（陈思雨，2027-05-10 16:42）」→「确认覆盖导入」→ 二次确认 → 新记录生效，旧记录标「已被替换」。

**场景 C：BI 双月 SKU 未映射**：列出全部未映射 SKU、出现行数、首次出现行号，链接 SKU 对照表。

**场景 D：BI 校验通过**：摘要 + 「月 × 店铺 × 站点 × 品类 × 新品/老品」归集预览（AC-F09-06）。

**场景 E：历史导入**：按同一模板上传，最多 24 个期间，显示 2025-01 至 2026-12 各月入库情况。

## 4. 信息架构

1. 标签页：金蝶月度 / BI 双月 / 历史金蝶（最多 24 个月）
2. 上传卡片：标题、最近导入期间、文件选择区（说明 60 秒时效）、必需列说明、「上传并校验」
3. 校验中提示
4. 校验结果：未通过（问题汇总 + 问题列表）或通过（摘要 + 侧栏信息 + 覆盖提示 + 放弃 / 确认导入）
5. 历史标签页：24 个月入库状态网格
6. 导入记录表

## 5. 界面内容

### 5.1 元素清单

| 元素 | 内容 |
| :--- | :--- |
| 金蝶必需列 | 期间（YYYY-MM）、金蝶科目、部门、平台/店铺、站点、发生额 |
| BI 必需列 | 月份（YYYY-MM）、店铺、站点、SKU、销量、本币销售额、币种、广告费、平台费用 |
| 金蝶问题列表列 | 行号（「第 1,206 行」）、问题类型（期间格式错误 / 部门不在主数据中 / 店铺不在主数据中 / 站点不在主数据中 / 金蝶科目未映射）、涉及编码或名称（等宽）、处理方式（链接对应主数据页） |
| BI 问题列表列 | 行号（SKU 未映射写「第 n 行起 · 共 m 行」）、问题类型（月份格式错误 / 店铺不在主数据中 / 站点不在主数据中 / SKU 未映射）、涉及名称或 SKU（等宽）、处理方式（链接渠道与店铺 / SKU 对照表）；汇总「共 x 个问题行、y 个 SKU 不在 SKU 对照表中」（AC-F09-08、AC-F09-05） |
| 金蝶通过摘要 | 期间、文件、行数、收入合计、成本费用合计；「未归属渠道」卡片：说明 + 按金蝶科目列行数与金额 + 合计 |
| BI 通过摘要 | 期间、文件、行数、SKU 数、新老品判定口径；归集预览表（月、店铺 · 站点、品类、新/老、销量、本币销售额带币种代码） |
| 覆盖提示 | 已有数据的文件名、导入人、导入时间；确认后替换该期间全部数据（金蝶 AC-F09-03；BI 按月份替换全部 BI 实际数，AC-F09-09） |
| 导入记录列 | 类型、期间、文件名、行数、导入人、导入时间、状态（生效 / 已被替换 + 被谁何时覆盖） |

## 6. 交互流程

```
选择文件 → 上传并校验（按钮变「正在校验…」）
   │
   ├─ 任一行有问题 → 整份不写入，列出全部问题行（金蝶 AC-F09-01；BI 月份格式 / 店铺 / 站点 AC-F09-08）/ 全部未映射 SKU（AC-F09-05）
   │
   └─ 全部通过 → 显示摘要（尚未写入）
         ├─ 期间无已有数据 → 「确认导入」
         └─ 期间已有数据 → 覆盖提示 →「确认覆盖导入」→ 二次确认弹窗
                → 用新文件替换该期间全部数据，旧记录保留并标「已被替换」（金蝶 AC-F09-03；BI AC-F09-09）
         入库后：
           金蝶：无店铺辅助核算且非部门费用科目的成本费用行计入该月「未归属渠道」（AC-F09-02）
           BI：按 SKU 对照表归集到 月×店铺×站点×品类×新老品（AC-F09-06）
           系统用全部生效预警规则重新评估受影响月份（AC-F11-01，结果见 PAGE-F11-01）
         「放弃本次上传」→ 不写入任何数据
```

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 正常 | 有导入记录 | 上传卡片 + 导入记录 |
| 校验中 | 上传后 | 骨架条 +「正在校验 文件名（行数）…」，上传按钮不可再点 |
| 校验未通过 | 有问题行 | 不利色提示框 + 问题汇总 + 列表 |
| 校验通过 | 无问题 | 有利色提示框 + 摘要 + 覆盖提示 + 操作 |
| 空 | 从未导入 | 「还没有导入过实际数」+ 说明 + 「导入历史金蝶数据」 |
| 加载 | 进入页面 | 骨架行 |
| 错误 | 请求失败 | 「数据加载失败」+ 重试 |
| 无权限 | 非财务BP | 「实际数导入仅对财务BP开放」 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 历史文件超过 24 个期间 | 校验不通过，提示期间数超过上限（AC-F09-04「最多 24 个月」） |
| 同一店铺名多行出错 | 每行单独列出（行号不同） |
| 覆盖确认前离开页面 | 不写入 |

## 8. 业务规则与校验

| 校验项 | 适用 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 期间格式 | 金蝶、历史 | YYYY-MM | 「期间格式错误」+ 原值 |
| 月份格式 | BI | YYYY-MM | 「月份格式错误」+ 原值，整份不写入（AC-F09-08） |
| 部门 / 店铺 / 站点 | 金蝶、历史 | 必须在主数据中 | 「部门 / 店铺 / 站点不在主数据中」+ 名称 |
| 店铺 / 站点 | BI | 必须在主数据中 | 「店铺 / 站点不在主数据中」+ 名称，整份不写入（AC-F09-08） |
| 重复月份 | BI | 已有数据的月份须确认覆盖 | 覆盖提示 + 二次确认（AC-F09-09） |
| 科目映射 | 金蝶、历史 | 金蝶科目须映射到预算科目 | 「金蝶科目未映射」+ 编码与名称 |
| SKU | BI | 必须在 SKU 对照表中 | 列出全部未映射 SKU |
| 期间数 | 历史 | ≤ 24 | 超限提示 |

- 新老品判定：某月最后一天早于首次上架日期加 12 个月为新品，否则老品（AC-F02-04）。
- 审计：每次导入记录操作人、时间，保留 ≥ 3 年，不能删除（NFR-004）。
