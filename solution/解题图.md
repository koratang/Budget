# 预算管理平台 · 解题图（终版待确认）

决策：年度全面财务预算——定全年净利润目标，拆到渠道×站点×品类与部门，按月滚动
结果指标：净利润达成率（上半年 90%–110%）

可控变量（杠杆）                       过程指标                                   结果
- 渠道×站点×品类销售目标（量、价、折扣） → 收入达成率                             → 净利润达成率
- 广告费率（TACoS）                     → 毛利率、广告费率
- 采购/备货节奏（PMC 预测输入）          → 库龄>180天占比、仓储费
- 新品/新渠道投入（保守放量规则）         → 新品/新渠道贡献利润
固定成本（列示不作杠杆）：部门费用额度    → 额度使用率 vs 时间进度
        ↑                                                                   │
        └── 归因：偏差拆到 渠道/站点/品类/部门/科目 ←── 金蝶月度实际（约1个月）+ BI 品类（双月）←┘
外部环境：汇率、海运运价、关税、平台政策与费率、旺季、竞品价格

解法：轻量预算平台（驱动因子模型；目标版/滚动预测版分离；偏差报告+预警规则；预算规则库）
最小切口：数据小试 → Amazon 美国站回测 → 扩展全渠道，编 2027 预算
