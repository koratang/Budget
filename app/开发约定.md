## 运行

- 数据库：本机 PostgreSQL，库 `budget`（开发）与 `budget_test`（测试），账号 `budget` / 密码 `budget`。
- 后端：`cd app/backend && .venv/bin/uvicorn app.main:app --port 8000`（开发配置 `APP_ENV=dev DEV_IDENTITY_SWITCH=true`）。
- 前端开发：`cd app/frontend && npm run dev`（代理 /api → 8000）；交付：`npm run build`。
- 钉钉替身：`.venv/bin/uvicorn dingtalk_stub.main:app --port 8090`；后端配置 `DINGTALK_BASE_URL=http://127.0.0.1:8090`。

## 接口约定

- 前缀 `/api`；JSON；时间 ISO 8601（Asia/Shanghai）。
- **金额、比率、汇率一律以字符串传输**（Decimal）。比率接口单位为「百分数字符串」，例如 `"12.5"` 表示 12.5%；后端存小数。展示用格式化字段另给（例如 `amount_display: "¥ 12,345.67"`）。
- 错误：HTTP 4xx + `{"code": "英文代码", "message": "中文提示", "details": {...}}`。未登录 401 `unauthenticated`；越权 403 `forbidden`，message 固定「无权限」；校验 422 `validation_error`；冲突 409。
- 会话：登录后设置 HttpOnly Cookie `budget_session`；8 小时无操作失效。
- `GET /api/me` →
  ```json
  {"user": {"id": 1, "name": "林晓", "dingtalk_userid": "..."},
   "roles": ["finance_head"],
   "scopes": {"departments": [], "channels": [], "stores": [], "customers": []},
   "all_company": true,
   "menus": ["workbench", "tasks", ...],
   "dev_switch": true}
  ```
- 角色代码：`ceo` CEO、`finance_head` 财务负责人、`finance_bp` 财务BP、`operations` 运营、`b2b` B端业务、`logistics` 物流物控、`dept_head` 部门负责人、`dept_budget` 部门预算专员。
- 开发身份（DEC-002/DEC-013）：`GET /api/auth/dev-users`、`POST /api/auth/dev-login {"user_id": n}`；仅当 `APP_ENV=dev` 且 `DEV_IDENTITY_SWITCH=true` 时注册，生产配置下 404，且生产配置开启该开关时启动失败。
- 钉钉：`GET /api/auth/dingtalk/qr-url`、`GET /api/auth/dingtalk/callback?code=`、`POST /api/auth/dingtalk/h5 {"auth_code"}`。

## 质量

- 后端金额全链路 Decimal，禁止 float。
- 每个功能组：pytest 覆盖其 AC 的业务结论（期望值按需求公式手算，不由实现生成）；接口层验权限。
- 提交前：`pytest -q` 与 `npm run build` 通过。
