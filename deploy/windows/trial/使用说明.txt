预算管理平台 · Windows 免安装试用版

一、启动
1. 把压缩包解压到纯英文路径，例如直接解压到 D:\ ，得到 D:\BudgetTrial 文件夹（路径里不要有中文和空格）。
2. 双击「启动试用.bat」。首次运行约需 1 分钟（初始化数据库、写入演示数据），之后浏览器自动打开 http://localhost:8000 。
3. 若 Windows 弹出“已保护你的电脑”，点“更多信息 → 仍要运行”；若防火墙询问，选“允许”。

二、登录
登录页下方虚线框「开发模式身份切换」里选择身份即可进入，例如：
- 林晓（财务负责人）：发布编制任务、维护主数据、汇总提交 CEO
- 各部门负责人 / 运营 / B 端业务 / 物流物控 / 部门预算专员：填报与审批
- 周明远（CEO）：终审锁定
建议按“林晓发布任务 → 各填报人填报提交 → 部门负责人审批 → 林晓提交 CEO → CEO 通过锁定”走一遍。
发布编制任务时，演示数据里只有人力资源部配了部门预算专员；请在发布弹窗中取消勾选「部门费用」整组后只勾选「人力资源部」，
或先到「系统设置 → 角色与权限」给其他部门指派预算专员和负责人，否则系统会提示这些单位缺少填报人或审核人。
钉钉通知不会真的发出，可在 http://127.0.0.1:8090/_stub/messages 查看系统“发出”的通知。

三、停止与数据
- 关闭黑色命令窗口即停止系统；运行「停止试用.bat」同时停止数据库。
- 数据保存在 data 文件夹，删除该文件夹即恢复到初始演示数据。

四、说明
本试用版仅用于本机体验：使用开发身份切换、演示数据和本地钉钉替身，不连接真实钉钉，不要录入真实财务数据。
